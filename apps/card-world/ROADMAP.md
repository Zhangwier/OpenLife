# 卡牌世界 · 路线图

目标：把样稿打磨成一个能独立上线的游戏。新玩家不看说明也玩得进去；玩上几十小时，村子还在长；出了问题，看得懂为什么。

每一项做完都要：有测试或实际跑过、写进 `DESIGN.md`、不弄坏老存档。

## M1 开局与引导

新玩家进来就知道自己是谁、该干什么。

- [x] 标题页：继续 / 新的一生 / 操作说明；开着标题页时游戏暂停
- [x] 开局引导：头几步（走动、认识人、采东西、吃饭、看手艺本）随做随过，可以跳过；老存档不弹
- [x] 「下一步」目标条：引导做完以后接上成长阶梯，始终显示村子眼下最近的一个目标
- [x] 消息记录：最近发生的事（吐司一闪就没了，这里能翻回去看）

## M2 节奏：大事安排者

日子有起有伏，不是一条直线。

- [x] 按村子过得顺不顺（粮、心情、离上回出事几天）挑合适的大事：鱼汛、野果大熟、过路老人、耗子、发烧、寒潮、失火、吵架（商队、外乡人、海寇、旱涝沿用原来的排期）
- [x] 坏事前一天有预兆（村民念叨，也进提示和「记」），事后进村史
- [x] 难度：安稳 / 寻常 / 艰难 三档，只改意外的频率和轻重（在「?」里切换）
- [ ] 狼群、山洪这类要村民一起应对的大事；地图上标出大事发生的地方

## M3 看得懂

- [ ] 资源牌悬停或长按：还剩多少、多久长回来
- [ ] 村民牌：看得见的状态（累、饿、闷闷不乐、生病），看不见的心思要问
- [x] 动物：卧着、睡着、走动分得清，点开有一句在干什么（v64.8）
- [x] 林子里的狼群：成群撵鹿，白天卧着；饿急的动物会下山吃田，村里人赶走；木柜 24 格，渔网 1% 才破；冬天会织布衣（v65.1）
- [x] 人物年龄阶段：婴儿/幼童/半大孩子/成年/老年各一档头像，孩子不再一出生就是大人脸（v66）
- [x] 一天五分钟；野猪收到 7 头上限；蜂窝有蜜蜂、黑熊会掏；树分四档生长并给不同木头（v67）
- [x] 屋子/灶火灯光改成有渐变和柔光；狼重画，会潜行、嚎叫、怕火（v68）
- [x] 发烧只记村史，不弹“谁病倒了”提醒（v70.1）
- [x] 在船上点自动不再试图划船去岸上目标，先靠岸（v72.1）
- [x] 冬天风雪可从海上划回岸；海盗守船人不再显示成三条孤船（v73.1）
- [x] 野猪/狼平时留在深林，老存档外圈个体读档迁回（v74.1）
- [x] 走路过渡和游戏 tick 对齐，不再一卡一卡；动物单独调过渡并减少小步甩头（v76.1）
- [x] 动物 z z 睡着时不再跟随/躲避/移动，挨打才醒；作息统一成一大段醒/一大段睡（v68.2）
- [x] 野猪/狼退回深林；受惊连续跑一段，不再碰一下就后退再回来（v69）
- [x] 地图向东/南扩海、黑礁岛推远；海盗守船人有作息，进攻要真打/抢粮（v72）

- [ ] 地图上标出大事发生的地方

## M4 稳定与平衡

- [ ] 长期模拟回归：脚本化地跑两年，检查粮、柴、地力、林子、心情、人口不会崩，也不会无限堆
- [x] 料堆有上限（40）；满了村民自己接仓房，仓房/木柜里的东西数得出、取得到（v64.8）
- [ ] 存档版本号和逐版迁移；导入坏档有明确提示
- [x] 「新的一生」先备份旧档，「?」里能找回上一段人生
- [ ] 性能：上百张牌时帧率，拖动不卡
