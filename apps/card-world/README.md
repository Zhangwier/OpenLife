# 卡牌世界

开放人生的卡牌玩法：Stacklands 式的卡牌，放在一张由几块地拼成的自动生成地图上（家、农田、湖泊、森林、森林深处、高原、大山）。时间会自己流逝，村民按自己的日子过。

游戏直接进入牌桌，沿用浏览器 v1 存档。

## 运行

在仓库根目录：

```
npm start
```

然后打开 http://127.0.0.1:4173 。换一张地图：`http://127.0.0.1:4173/?seed=3`；直接看冬天：`http://127.0.0.1:4173/?day=13`。

## 玩法速览

- 直接拖「你」走过去，一次最远走到亮圈边上；放到一张牌上就和它一起做事。
- 点空地让人自己走过去时，镜头停在原处；点 ◎ 才把镜头拉回你身上。
- 夜里的屋子/灶火不再是死亮一块：中心亮、往墙根渐暗，墙外只有一圈淡淡柔光；火把是另一个小圆光。
- 谁发烧病倒只写进村史，不再弹提醒。
- 狼会低伏潜行、靠近才冲；开始围猎会嚎，遇到人和火会退。
- 动物显示 z z 睡着时是真的不动：不会跟着群走、不会躲人，挨一下打才会醒；醒着/卧着时才会挪动。
- 作息是一大段醒、一大段睡：鹿/鸭/山羊/野鸡/熊在夜里同睡，兔/野猪/狼/虎/狐狸在白天同睡，不再走一会儿睡一会儿。
- 正常速度下一天约 5 分钟；野猪最多 7 头，不再拱满林子。
- 栗子林、松林分幼苗/小树/成材/老林四档，砍一棵给 1–4 根木头（带斧子多一根）；野蜂窝有蜜时会飞小蜜蜂，黑熊也会来掏。
- 主角开着自动时，点空地或拖主角都会先取消自动；换成别人操作时，点空地只走那个人，主角会停下。
- 每开新的一生，栗子林、松林、湖岸这些资源点会按这一生重新排一次；同一个存档里它们仍长在原处。
- 夜里屋子、灶的火光只照屋里和贴墙的一圈，不再照到院子外面。
- 双方手里都有可交换的物资时，走近并点村民牌，打开「换东西」。对方根据自己的库存、需求和关系给出答复。
- 右上角 ☰ 里是村子、最近的事、声音、操作与存档。
- 左下角是你和能指挥的人（点开可以派活或直接拖着指挥）；右下角 ⟳ 是闲置时自动行动。
- 做东西在院里的工作台上：把料堆上去，人站上去；点开工作台能看现在会做什么。火塘只管煮、烤、熏、火把。
- 盖房：工作台上用芦苇编「墙板」，拖到地上就贴着格子线立成一段墙（一摞拖下去连成一排），再带上黏土站上去糊泥。「门板」（木头、麻绳）拖到一段墙上就开成门。四面围死后屋里显示还缺几张「草苫」（芦苇、麻绳），拖进屋里、站上去苫顶，才算屋里：冬夜不冻、下雨能躲、能放铺位。带着锤子站到墙上就拆。冬天泥墙停工。屋里挤了，会立墙的村民会自己在旁边接一间。
- 料堆满了：一个堆约放 40 份，公仓塞不下时村民会自己接一间仓房；仓房里的料堆数得出、也取得到，家里东西摊多了会钉木柜。
- 林子里的动物不活动时是卧着，不是钉住不动：过一阵会挪几步、换个窝；点开能看出它是睡着还是只卧着。老虎白天在深林里睡，夜里出来打猎，不认窝。
- 林子里有狼群：白天在深林卧着，黄昏到天亮成群撵鹿、山羊、兔子和野鸡；它们会避开人和火，不主动扑人。老存档读进来也会补一群。野猪和狼平时都在深林，老存档里跑到外圈的会被挪回深林。
- 地图向东、南各扩出一片海，黑礁岛移到更远的外海；海盗船会从那边开过来，守船人白天巡逻、夜里回窝。
- 受惊的动物会朝反方向连续跑一段（十几分钟），不会碰一下就后退两步再慢慢回来。
- 人和村民走路按游戏速度平滑过渡，不再一卡一卡；动物也用自己的过渡节奏，并减少了吃草时原地甩头。
- 鹿、兔、野猪饿极了会下山吃田；稻草人/篱笆能挡住，村里人看见会喊一声把动物赶走。
- 人物会随年龄换样子：孩子在婴儿、幼童、半大孩子、成年、老年各有一档头像，成年后有自己的通用像；具体的人保留自己的脸，只随年纪变老。美术图放到 `art/icons/baby.png` 等名字就会自动替换内置图。
- 工作台能做「布衣」（葛麻两份、麻绳一份），冬天村民会自己织；石矛、斧、锤、刀这些武器照旧能做。
- 木柜能收 24 样放得住的东西；渔网只有 1% 的机会扯破，破了只剩一束葛麻，直接重做一张。
- 打猎：把人物牌拖到野物身上，人就自己追上去打，不用先走到攻击距离以内；小动物挨一下会发懵，鸭子两拳能打倒。鸭子下水又没带石矛时，得等它上岸或换矛投。
- 小船：把人物牌拖到船上就上船；船也能像家具一样拖着走，拖到水上就能划。划船时船和人始终贴着，不会脱节。在船上不能开自动，先靠岸。
- 冬天风雪里不能往海外去，但可以从海上划回岸边；海盗守船人显示成人像，不会变成三条孤船。

- 阿黄看家：院里有鸭子、兔子、野鸡、狐狸会叫、会追，把野物撵出去；派它搬运时先干搬运。
- 换人操作：点左下角的人，按「✋ 换成他」，就像换了个人：拖他走、用他身上的东西、让他做东西。点你自己的牌换回来。
- 矿山：在矿道尽头的石壁上挖，挖得多了矿道就往里深一截，偶尔挖开铜矿、燧石脉。
- 开荒：工作台上削「界桩」（木头、葛麻），拖到草地上就划出一块荒地。想到地窖、粮窖、堆肥坑、造船以后，工作台上能做它们的「规划」牌，拖到地方就划好线。
- 点开东西只看眼前：名称、一两句看得见的状态、能做的事。地基没学过、又看不出下一步要什么时，走到会盖的人旁边，点开地基按「请教这一步」。
- 一摞牌拖最上面那张会整摞带走，混装的不同材料也一样；想只拿其中一种，拖它自己那一行，或点开单拿一份。
- 把材料和火/灶/桌堆成一摞，把人拖到这摞上就会开始做；材料从堆里扣，成品也留在堆上。
- 造好小船可以划到东南的黑礁岛：岛上有盐田和贝壳滩；盐能腌鱼腌肉，贝壳能串珠，带上岸就多一条进项。
