# 卡牌世界样稿（card-world）

开放人生的一个玩法样稿：Stacklands 式的卡牌，放在一张自动生成的河谷地图上。时间会自己流逝，村民按自己的日子过。
它是独立的静态网页，**不连游戏引擎**，数据都是示意。用来试手感，确定方向后再搬进正式的游戏。

## 运行

```
cd apps/card-world
python -m http.server 4181
```

然后打开 http://127.0.0.1:4181 。换一张地图：`http://127.0.0.1:4181/?seed=3`。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` / `style.css` | 页面和样式 |
| `app.js` | 玩法：卡牌、拖动、配方、时间、村民、动物、盖房子 |
| `mapgen.js` | 地图生成：高度、水系、地面、按规则放地点、修路、寻路 |
| `terrain.js` | 画地面：四季、山、树、果园、丛林、桥、潮汐 |
| `valley.js` | 第一块陆地「河谷」的内容：有哪些地点、牌、人 |
| `icons.js` / `art.js` | 示意图标；`art/icons/<名字>.png` 存在时自动替换 |
| `DESIGN.md` | 设计说明，按版本记录每一轮做了什么、规则是什么 |
| `art/ART_BRIEF.md` | 美术需求：要哪些图、尺寸、风格、放哪儿 |

## 玩法速览

- 直接拖「你」走过去，一次最远走到亮圈边上；放到一张牌上就和它一起做事。
- 右上角 ✎ 是手艺本：会做什么、记得多牢、盖房子和开荒。点 ? 看完整说明。
- 左下角是你和能指挥的人（点开可以派活或直接拖着指挥）；右下角 ⟳ 是闲置时自动行动。
