# 卡牌世界

开放人生的卡牌玩法：Stacklands 式的卡牌，放在一张由几块地拼成的自动生成地图上（家、农田、湖泊、森林、森林深处、高原、大山）。时间会自己流逝，村民按自己的日子过。

现在是仓库里唯一在跑的游戏。原来的引擎版已封存，这个页面**不连游戏引擎**，数据都是示意。

## 运行

在仓库根目录：

```
npm start
```

然后打开 http://127.0.0.1:4173 。换一张地图：`http://127.0.0.1:4173/?seed=3`；直接看冬天：`http://127.0.0.1:4173/?day=13`。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` / `style.css` | 页面和样式 |
| `app.js` | 玩法：卡牌、拖动、配方、时间、村民、动物、盖房子 |
| `mapgen.js` | 地图生成：各种地块（平原、森林、森林深处、湖、高原、大山＋矿道）、按地点放东西、修路、寻路（绕开院墙）、林深；地块拼接 |
| `terrain.js` | 画地面：四季、山、树、丛林、院子地板、矿道盖板、田里的庄稼、潮汐 |
| `valley.js` | 地块怎么拼、每块地上有哪些地点、牌、人 |
| `voice.js` | 村民说的话和心里想的（改编自旧引擎的语料） |
| `people.js` | 人物档案：喜好、怕什么、生日、四季的话、心意事件、会托你办的事 |
| `village.js` | 村子：六级成长阶梯、谁会来投奔、节日 |
| `icons.js` / `art.js` | 示意图标；`art/icons/<名字>.png` 存在时自动替换 |
| `DESIGN.md` | 设计说明，按版本记录每一轮做了什么、规则是什么 |
| `art/ART_BRIEF.md` | 美术需求：要哪些图、尺寸、风格、放哪儿 |

## 玩法速览

- 直接拖「你」走过去，一次最远走到亮圈边上；放到一张牌上就和它一起做事。
- 右上角 ✎ 是手艺本：会做什么、记得多牢、盖房子和开荒。点 ? 看完整说明。
- 左下角是你和能指挥的人（点开可以派活或直接拖着指挥）；右下角 ⟳ 是闲置时自动行动。
