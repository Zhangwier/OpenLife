# 居民立绘

河岸台地十六位居民各一张半身立绘，文件名即 `data/river-terrace.json` 中居民的 `key`，
图鉴「人物」页按 key 自动匹配（缺图时显示姓名首字）。

- 来源：AI 图像模型生成（2026-10-16），统一提示风格为「淡彩水墨 / 柔和水粉、鼠尾草绿与陶土色、
  羊皮纸底、三分之四侧身半身像」，并逐人写明年龄、职业、手中物件（陶杯、木耒、木桨、陶釜、芦苇捆等）。
- 处理：裁成 3:4，缩放到 480×640，JPEG 质量 3（ffmpeg）。
- 2026-10-17 补：`healer.jpg`（蓍婆）、`stonesmith.jpg`（阿砺）按同一风格以现有立绘为参照生成；`reed-worker.jpg` 以原图为参照重绘，镰刀改为绑在木柄上的打制石镰（原“金属镰”问题已解决）。
