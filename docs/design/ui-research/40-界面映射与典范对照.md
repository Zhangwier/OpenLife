## 1. 此刻（主场景）· 电脑 1440

**照 Dwarf Fortress 的"框"**：四边各一条功能带，中间留给画。我们不需要四条，**两条就够**：

```
┌──────────────────────────────────────────────┐
│ 顶栏：第三年·立秋·傍晚  河岸台地   肚子空着    │ 48px 无底板
├──────────┬───────────────────────┬───────────┤
│ 左栏 240 │      场景画（居中）     │ 右栏 320  │
│ 人 / 事  │      + 下方叙事软底     │ 行囊 / 村史│
│          │                       │           │
├──────────┴───────────────────────┴───────────┤
│ 底部动作条：地点 / 劳动与休息 / 时间安排        │ 56px
└──────────────────────────────────────────────┘
```

**照 A Short Hike 的氛围分层**（`scene-fx.js` 已有能力）：远景云 60s、中景炊烟 8.5s、近景落叶 12s、火光闪烁 2.3s。**层与层之间周期必须不同**，否则会看出"一起呼吸"的破绽。

**不做什么**：不在画面正中放任何 HUD；不给场景加霓虹描边；不做人物走动。

---

## 2. 此刻 · 手机 390

**照 Fallout Shelter 的剖面**，而不是平面俯视：

| 区域 | 高度 | 内容 |
| --- | --- | --- |
| 顶栏 | 44 | 时间 · 地点 · 一项状态（三选一显示最紧急的） |
| 场景 | 38vh | 院落剖面 + 人物 + 一个热点 |
| 叙事 | 自适应 | 软底，2–3 段，点击推进 |
| 动作 | 底部 56 | 「做事」按钮 → 底部抽屉 |

**关键决定**：**手机顶栏只显示一项状态**，其余进「人生」页。RimWorld 的资源列表能全显示是因为屏幕 1920 宽；390 宽放四个数字就是在给自己找麻烦。

---

## 3. 叙事区（两端共用）

照 **Disco Elysium 的无边框半透明**，而不是我们现在的 `.panel` 卡片：

```css
.story {
  max-width: var(--measure);            /* 640 */
  padding: 24px var(--measure-pad);
  background: linear-gradient(180deg,
    var(--bg-fade-0) 0%,
    var(--bg-fade-55) 10%,
    var(--bg-fade-55) 90%,
    var(--bg-fade-0) 100%);
  /* 不加 border、不加 border-radius、不加 box-shadow */
}
```

照 **80 Days 的节奏**：一段 1–3 句；每段 180ms 淡入 + 上移 6px；点击立即出下一段；**设置里可关**。

照 **Pentiment 的字体角色**（降到中文三档）：

| 谁在说 | 字体 | 颜色 |
| --- | --- | --- |
| 叙述者 | `--serif` | `--ink-narration` |
| 村民 | `--sans` | `--ink-speech` |
| 头人/公文 | `--serif` + 字距 .04em | `--ink` |

## 4. 选项木牌

照 **Reigns 的一卡一两难**，结构固定三行：

```
┌─────────────────────────────┐
│  登门                         │ 16px  做什么
│  会得罪阿石                    │ 13px  --ink-cost 代价
│  没有界石，去不了              │ 13px  --muted 不可选原因
└─────────────────────────────┘
```

照 **Disco Elysium 的"谁在说"**，把「代价暗示」升级成**归属标注**：

- `会得罪阿石`（人）
- `村里人会记着`（群体）
- `今年过冬会紧`（时间）

**状态**（§6.3）：默认 / 悬停 / 按下 / 禁用 / 危险（左侧 3px 朱砂竖条，不整块变红）。

---

## 5. 行囊

照 **ACNH 口袋抽屉**：手机上从底部拉出，三档高度（96 / 52vh / 90vh）；拖过 25% 或速度 >0.5px/ms 才换档。

照 **Stardew 的格子 + 详情在下**：格子 4 列（手机）/ 6 列（电脑）；点一格，详情出现在格子下方而不是新页面。

**不给数字**：负重不用 `12.4/20`，用「背得动」「有点沉」「背不动了」。

---

## 6. 熟人 / 人物志

照 **CK3 的"同一对象同一张卡"**：场景里点头像牌、左栏点名字、村史里点人名，**打开的都是同一张人物卡**。

照 **Norland 的关系线型编码**：

| 关系 | 线 |
| --- | --- |
| 血亲 | 实线 `--line-strong` |
| 婚姻 | 双线 |
| 敌对 | 虚线 `--danger` |
| 只是认识 | 点线 `--line` |

照 **RimWorld 的头像条**：`PersonChip` = 3:4 立绘 + 名字 + **一个文字状态**（「在忙」「想跟你说话」「生你气」），不用表情 emoji。

---

## 7. 村史

照 **Victoria 3 的"为什么"分解**：每条村史下面一个「为什么」，展开 2–4 环因果，环与环之间细线连接，涉及玩家本人的环加赭石边。

照 **江南百景图的长卷**：电脑上横向长卷（可拖拽），手机上改为竖向时间轴 + 粘性年份标题。

**空状态**照 Wildermyth：不写"暂无记录"，写「这一年没什么大事」，并折叠。

---

## 8. 断事 / 求票

照 **CK3 的两难卡** + **Reigns 的图标情绪**：

```
┌───────────────────────────────────────┐
│ 阿石想当头人                            │
│ 「他昨天在你家门口站了很久。」            │
├───────────────────────────────────────┤
│ 当众支持他      阿石高兴 · 陶叔会沉默     │
│ 不表态          两边都不满意             │
│ 推举陶叔        得罪阿石 · 陶叔意外       │
└───────────────────────────────────────┘
```

**关键**：每张卡上的"谁高兴/谁不满"**必须有名字**，不能写"部分村民"。

---

## 9. 推举

照 **Against the Storm 的三选一**：全屏 + `--scrim-deep`(.58) + 三张卡 + 卡片 250ms 依次弹入（间隔 60ms）。

手机上改为 `scroll-snap` 横向翻页，一屏一卡，投票按钮固定在底部。

---

## 10. 琢磨 / 试做

照 **Roots of Pacha 的"发现卡墙"**，但改成**反向**：先有"难处"，才有"想法"。

```
左：我注意到的难处（便笺，每条一句）
中：选中的难处 → 我想到的线索（纸片拼贴，最多 3 张，空的是空白纸）
右：试做记录（每次失败一句话原因）
```

失败文案照 Pentiment 的具体性：不写"试做失败"，写「绳子太松，扛不住」。

---

## 11. 「这些年」总结页

照 **Wildermyth 的依次淡出** + **80 Days 的段落节奏**：

- 全屏，背景是当前季节场景 + 深遮罩
- 中央一张纸（640），标题宋体 32
- 「家里」「村里」「你自己」三节，每节 2–5 句
- 段落 180ms 依次出现（不是一次性全出）
- 底部两个按钮：「回到日子里」「翻村史」

**大灾年份**照 Frostpunk：标题下加一行朱砂小字「那年大水」，整屏降饱和 0.2（1200ms 过渡）。

## 12. 设置

照 **Roadwarden 的"字体可选"** + **GAG 的"设置全部可保存"**：

| 分组 | 项 |
| --- | --- |
| 阅读 | 宋体阅读 / 统一易读字体 / 逐段推进 开关 / 字号 100–200% |
| 动效 | 减少动效 / 氛围动效开关 |
| 显示 | 亮 / 暗 / 跟随时辰 |
| 操作 | 键盘快捷键表 / 触控热区放大 |

---

## 13. 印章时刻（无对应，自研）

只在三处：**当选 / 立规矩 / 重大传承**。

- 300ms：1.2 → 1 缩放 + −3° 旋转 + 轻微回弹
- 朱砂色，一屏只出现一次
- 盖章后 2s 内不可再触发
- `prefers-reduced-motion` 下直接显示，不做动画

---
