## 三条最重要的结论

1. **UI 必须比场景亮**（`特效 ≥ UI > 角色 > 场景`，腾讯实测结论）；我们现在是反的。
2. **叙事区不该是卡片**——4 款文字游戏没有一款把正文塞进带边框的卡片。
3. **手机上每个数字都要付租金**——顶栏只留「时间／饥饿／地点」三项。

- `A` 级：官方 Wiki、开发者访谈、字体厂商案例、可逐屏核对的界面库。
