# 像素地图素材提示词模板

仅在生成/编辑素材时读取。先读 [工作规范](../PIXEL_ART_WORKFLOW.md)，明确本轮基线和原生尺寸。方括号内容由任务清单填入；工具输出尺寸不等同于最终原生尺寸。

## 地表

```text
用途：游戏的独立平面地表材质。
参考图角色：[原始画风参考 / 已认可场景]，观察其中安静的地表区域。
输出：[裸土 / 低矮草坪]，均匀俯视，无地平线，边到边铺满。
表现：较大安静色块，少量成组变化，低对比；细节集中而非全屏均匀碎点。
排除：房屋、树、直立花草、道具、物件阴影、UI、文字。
目标原生尺度：[宽×高逻辑像素]；另行验收拼接边缘。
```

## 独立对象

```text
用途：可独立摆放、排序或交互的 [对象]。
输入：[图1] 是画风参考；[图2] 是编辑目标（如有）。
保持：[轮廓、比例、朝向、身份、已有服饰/材质等具体不变量]。
修改：[本轮只改变的一项主要问题]。
输出：一件完整对象、真实透明背景，根部/脚底可确定。
视角：与已认可场景一致的斜俯视二维表现；光从左上，按场景修正。
排除：地面岛、其他物件、投影烘焙、光晕、文字、假透明棋盘。
目标原生尺寸：[宽×高]，与人物和门洞比例共同验收。
```

## 人物动画

```text
编辑目标：[人物原稿]；保持身份、头身比、发型、衣服、朝向和配色。
输出：[帧数] 个动作，按 [行列] 等格排列，统一帧尺寸、头部尺度和脚底基线。
动作顺序：[逐帧说明]，肢体不跨格，充分留边。
原生帧画布与有效人物高度：[尺寸]；枢轴：[脚底坐标]。
真实透明背景，边缘干净，去掉原稿光晕。
验收：原生尺寸静看、逐帧切换、循环播放、放回实际场景四次检查。
```

生成后先核对真实布局和帧边界，再写清单。源图可能不是提示词中指定的像素尺寸或等格布局，不能假定生成工具严格遵守。若不合格，修订素材或保留为试稿，不让渲染器悄悄纠正并声称通过。

## 对当前素材做局部修改

同时写出“保持什么”和“只改什么”。例如：保持屋形、门窗位置与视角，只减少屋顶重复碎纹理；保持树干与主要分枝，只调整树冠叶簇组织。将修改放回同镜头场景比较后，再决定是否采用。
