# UI 与交互第三轮（2026-10-20）：二级页面、错误提示、深色与大屏

入口：`apps/web/public/pages-ux.js`，在 `<head>` 里最先加载，并自己挂上 `pages-ux.css`。
它不改 app.js、shell.js、player.js 的渲染逻辑，也不发任何游戏动作。

| 界面 | 以前 | 现在 |
|---|---|---|
| 动作失败（纯文字模式） | 拒绝理由写进被隐藏的 #actionFeedback，toast 也被清空，玩家什么都看不到 | 底部弹出红边的「没做成」提示条，写着游戏给的原因，8 秒后自动收起 |
| 本地服务断开 | 报错是英文 "Failed to fetch"，而且同样看不见 | 报错换成中文；顶部常驻「连不上本地世界服务」横幅，带「重新连接」，连上后横幅自动消失；横幅和顶栏都粘在顶部，翻页时互不遮挡 |
| 侧栏（更多资料里的 6 个页面） | 「更多资料」收着，高亮的却是「人物」 | 自动展开分组，只高亮当前页，分组标题也带上颜色；手机底栏仍用「人物」兜底 |
| 记忆与历史 | 时间线竖线穿过年份数字；同一年每条都重复写年份；每条都挂一句「仍留在这个世界里」 | 年份右对齐放在轴线左边，圆点落在轴线上；同年只写一次；默认说明不再显示，「人物已离开」这类说明保留 |
| 模块管理 | 37 张卡没法查；已加载分组里每张卡都重复「当前世界已加载」 | 加搜索框（多个词同时命中、不分大小写、显示「n / 37」、搜不到有提示、命中未接入的模块时自动展开那一组）；去掉重复徽标；≥1500px 排三列 |
| 家族谱 | 只有自己一个人时，只有一张小卡和大片空白 | 补一张「家族怎样延续」：当前家庭状态，以及结成伴侣、生养孩子、交棒三步，带「去看人际」按钮 |
| 大屏生活页（≥1600px） | 内容挤在 1320px 中间，人生纪事要往下翻才看得到 | 右侧加一条 400px 的粘性栏，放人生纪事和心里记着的事；换到别的页面或屏幕变窄时，纪事自动回到原位 |
| 深色模式 | 图鉴卡片写死成半透明白色，在深底上发灰，字看不清；故事页按钮用了没定义的 --paper，结果是浅底浅字 | 改用 surface 令牌，文字对比度分别达到 7.95 和 11.46；手动深色和跟随系统两种情况都覆盖 |
