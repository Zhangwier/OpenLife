## 题目二：新手引导导览（coach-ux）
- 「指给我看」→ 分步导览：目标外压暗（固定定位聚光框，不改目标层级）、说明气泡跟着目标（下方放不下放上方，再不行贴底），第 n 步 / 共 3 步 + 进度点，上一步 / 下一步 / 结束引导。
- 键盘：焦点落在「下一步」；→ ← 翻步；Esc 结束（不记成看过）。最后一步「完成，开始生活」= 原来的「知道了」。
- 手机：气泡贴底栏上方；引导卡三步只留标题一行排开（说明进气泡），卡片高度从一整屏降到约 1/3 屏。
- 步骤仍是 ui-polish.js 的 COACH_STEPS，记忆键不变，菜单「新手引导」照旧能重开。
