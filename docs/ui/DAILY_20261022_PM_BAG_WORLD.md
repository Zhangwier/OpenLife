## 题一：HUD · 行囊栏（bag-ux）
1. 「随身」下一排格子（实心=占用、虚线=空着），「负重」下一条细条；仍遵守“行囊不给数字”，件数只在 title / 读屏。
2. 同名同状态的非容器物品叠成一摞，卡角写「两份 / 三份 / 好几份」，卡片画成叠放；点它照旧打开第一份。
3. 去掉每张卡重复的「在手中」，容器只留「容量」半句。
4. 补回第二轮的「空位」虚线格（原逻辑读数字，数字改成词后失效）。
5. 物品详情：位置句改成「随身带着 · 此刻在…」，标题加大，桌面操作两列。
6. 「亲手留下的作品」没有作品时折叠标题后写「还没有」。

## 题二：视觉风格统一 · 时代与世界（world-ux）
1. 三个数字铺满整行；手机标签不再拆成「持续存在的聚 / 落」。
2. 只有占位句的小节（时代人物、思想与学派、流传中的历史、后世仍记得的人…）默认收起，页尾一块「这个时代还没出现」列出名字，可展开/收起；某节有了内容自动回到正文。
3. 桌面 ≥1000px 小节两列；时代脉搏占满一行。
4. 小节眉标 / 正文 / 说明三层字号统一。
