# UI 与交互第二轮（2026-10-20）：操作之后的反馈

第一轮管的是“看得懂”（导航、按钮、状态条、对话框）；第二轮管“做了之后知道发生了什么”。
入口：`apps/web/public/scene-ux.js`（自己挂 `scene-ux.css`），在 `index.html` 最后加载。
它只观察已有的渲染结果再补一层，不改 app.js / stories.js / shell.js 的渲染逻辑，也不发任何游戏动作。

| 界面 | 以前 | 现在 |
|---|---|---|
| 场景操作菜单 | 从人物/物件清单点开后，菜单标题被顶栏盖住；关掉后停在菜单原处，刚才点的人在屏幕外 | 标题完整露在顶栏下；关掉后滚回刚才点的人并把焦点放回去 |
| 行动结果 | 纯文字模式下结果只写进「人生纪事」，人在页面下方时看不到 | 纪事不在视野时，底部弹出结果条（叙述 + 变化标签 + 看纪事），7 秒后收起，悬停不收；最新一条纪事有左侧标记 |
| 状态条 | 数字变了没有提示 | 变化的那一项加色框和 +n / −n：饥饿升高红、屋顶修好绿、活动格灰 |
| 移动面板 | 村里免费的步行（腿脚快天赋）也标成「屋内」 | 屋内移动标「屋内」，村里免费步行标「不花时间」 |
| 送礼 | 图标退化成圆点 | 礼盒线条图标 |
| 故事页 | 17 件事全部平铺，15 件接不了 | 顶部分区导航（粘顶、带在办/可接/成就计数）；接不了的折进「还没到时候的事（n）」；能接的按钮是主按钮 |
| 行囊 | 「2/4 件」只有数字 | 剩下的格子画成虚线空位 |

验收：`verify/ui-round2-check.mjs`（zip 内）在 1366×800 和 390×844 各跑 14 项，全部通过。
