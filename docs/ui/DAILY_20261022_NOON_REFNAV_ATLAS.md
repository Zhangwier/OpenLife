# 每日 UI 优化 2026-10-22 午场：手机资料页切换条 + 「地图与地点」页

基线 origin/main 8f0c5a6。新增 `refnav-ux.js/css`、`atlas-ux.js/css`，由 `pages-ux.js` 顶部两行 import 挂上（不改 index.html、shell.js）。

## 题一：手机「资料页」切换条（refnav-ux）
- 范围：手机布局（html.is-phone 或底栏为 fixed）下的六个资料页：故事、家族谱、地图、时代、记忆、图鉴。
- 页面标题下一条粘性横向切换条：「‹ 此刻」+ 六页；当前页实心高亮、aria-current="page"；当前格看不见时只滚到刚好露出。
- ← → 循环、Home / End 到两端；按钮高 ≥40px。
- 手机底栏：资料页一律高亮「人生」（原来地图页亮「此刻」，故事页不亮）。主页面行为不变；桌面侧栏不受影响。

## 题二：「地图与地点」页（atlas-ux）
- 页首加总览：n 片地图 · 共 n 个地点 · n 处值得留意；共同的限制只在页首说一次，改成玩家话。
- 地图卡：「结构校验通过」不显示，只有出问题时显示醒目的「资料需修复」；三颗药丸改成「数字 单位」读数；重复的限制句删除。
- 「查看事件点 / 查看区域」两个折叠并排，展开的那个占满整行；桌面 ≥900px 两列，展开的卡占满两列。
