# 地图生活交接（2026-10-31 起，两轮）

基线：`integrate/history-lab@fe58e5e`（含他人未提交的 pixel-scene 美术改动，本轮未动）。依据：[实施计划](../plans/map-life-implementation-2026-10-25.md)、[策划书](../design/map-life-design-2026-10-25.md)。用户指令：完成游戏、UI 可大幅重构；中途“去掉四周 UI 文字，参考星露谷”；第二轮“完整做完，给成熟版本，画面风格也要，可以换像素风”。

## 玩家现在看到的

- **标题页**：用 v6 素材画的活的像素村落作背景（四个村民走动、镜头缓移、按真实月份选季节），菜单是木框羊皮纸板。
- **此刻 = 全屏地图**：点地走路（不花时间、不推进日期），点人/物出木框对话框，选一件事会自动走近再做；人说话进入带像素头像、逐字出现的对话框；拿到/用掉东西头顶飘字；过一天压暗报日期；进新地方屏幕上方出地名。
- **HUD**：右上日期/天气/体力格/饱饿，右侧图标列（行囊、熟人、人生、日志、时间、声音、菜单），底部随身物品栏（用地图同一套像素画）。人名只在选中或鼠标指着时出现。
- **其他页面是叠在地图上的面板**：行囊/熟人/人生/日志/故事/家族等全部以木框羊皮纸面板打开，顶部是页签，“回到地图”或 Esc 关闭；菜单、存档、日程、新人生弹窗都换成同一套皮肤（`html.game-skin` 令牌）。
- **出门 = 村子地图**：像素村落总图（16 个地点、四季变化），点地点看代价与说明，“出发”后先走到路口再真实到达；手机上图下附地点列表。
- **人物**：每人独立外貌（年龄段、体型、发型、衣色来自与头像同源的 `appearanceFor`），四向行走 + 呼吸；村民在自己位置附近走动，被选中时回位并转向玩家；狗在走。
- **场景**：室内（铺位/储物架、火塘与暖光、窗、挂着晾的草束）；户外按地点类型生成河岸/田/林/窑/黏土坑/集市/祠/渡口等，并有各自的道具（柴垛、陶堆、摊子、独木舟、立石……）；四季地表与树叶（春花、夏深、秋叶黄橙、冬雪与屋顶积雪）；水面闪光、雪雨粒子、晨昏光色。
- **村子在一天里动起来**：玩家用掉一天约四分之一后村民各自去做活的地方，四分之三后回家（见下）。
- **声音**：原有合成音乐/环境声随地图所在地点与时段切换；新增脚步、拾取、对话、开门、新一天的短音效。

- `npm test` 全部通过（998 项起），新增：`local-grid`、`local-map-layout`（49 个场景锚点可达）、`map-targets`（每个动作恰在一个目标上）、`day-phase`（往返原样；有无日内移动，次日村子状态完全相同）、`map-life-web` 集成。`typecheck` 0 错误，`design:check`、`catalog:check` 通过。
- `node apps/web/dev-browser-smoke.mjs`（文字页，真 Edge 触控）：通过；脚本改为先关地图再测文字页，点击前把目标滚到中间（原先会被底部导航挡住）。
- 地图路径：`node apps/web/map-browser-smoke.mjs`（真 Edge 手机触控：新人生→点地走路→交谈→村子地图出行→面板→重载续玩位置不变）。结果以最近一次运行为准。
- 无头 Edge 截图检查过桌面 1366×800 与手机 390×844@3x 的标题页、室内、户外八类地点、四季、面板、菜单、存档、日程、村子地图。

## 调整与已知边界

- `OPENLIFE_DAY_PHASES=0` 关闭日内时段，仅给需要“空村子”精确计数的测试（M2-B 织袋测试已加）；正式游戏默认开启。日内遇到村民会触发原有的故事/馈赠规则，这是有意的后果。
- `source-size-budget` 为既有超限的 `pixel-scene.js`（他人美术小样，HEAD 已超）补了上限条目。
- 未做：真机触控与性能测量、真人试玩；村民日内只在“家/做活处”两点之间（按玩家用掉的时间分三段），还没有更细的日程；远行（地区图）仍走文字页；人物是程序生成像素小人，不是手绘逐帧动画。
- 地图可在菜单「显示 › 地图」关闭，回到原文字页与原测试路径。
