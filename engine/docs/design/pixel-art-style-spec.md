# OpenLife 像素场景 · 美术风格规格（2026-10-25）

> 目标风格：低饱和像素画，参考 NicoDocci 式乡村俯瞰 + 夜间灯塔小镇的色层与纵深。
> 适用文件：`apps/web/public/pixel-scene.js`（程序化像素视图，主战场）、
> `scene-fx.js` / `scene-depth.js` / `pixel-scene.css`（粒子与 2.5D 站位，辅助）。
> 渲染基线工具：`node apps/web/dev-art-shot.mjs --season=<季> --sky=<天>`，
> 出图到 `artifacts/art/`。**每改一处都必须出对照图（改前/改后同参数），不接受"感觉好多了"。**

## 八条硬性标准（验收逐条对照）

### A1 · 没有黑描边
角色、建筑、树冠、器物靠**明暗块面**区分，不用一圈深色勾边收形。
- 现状缺陷：`pixel-scene.js` 树冠色阶 `shades[0] = leaf × 0.14` 太黑，形成事实上的描边；
  树干、屋顶、土路、篱笆、人物外圈都有深色收边。
- 要求：任何形体的最外圈颜色与它外侧背景的明度差 ≤ 内部分层之间的明度差。
  暗部允许压深，但必须是"块面里最暗的一块"，宽度 ≥ 2px 且带噪，不是 1px 连续线。

### A2 · 配色
底色用低饱和**橄榄绿 / 苔绿 / 泥褐 / 灰黄**；高饱和只做**少数点缀**
（橙色秋叶、黄色小花、青蓝灌木、暖黄窗光）。
- 现状缺陷：整体偏灰发闷；雪天尤其脏。
- 要求：给出明确色板（hex），底色饱和度（HSL S）控制在 8%–30%；
  点缀色允许 S 到 55%–70%，但单屏点缀像素占比 < 1.5%。
- 建议色板（可在实现中微调，但必须登记在本文件）：
  - 草/苔底：`#3a4426 #45512e #506038 #5c6c40`（阴）→ `#6a7a48 #7c8a52`（阳）
  - 泥/土路：`#6a5136 #7a5f42 #8a6f4e #9a7f5c`
  - 点缀-秋叶橙：`#c8862e`；点缀-小花黄：`#d8c04a`；点缀-青蓝灌木：`#3e5a52`
  - 透光/落叶亮点：`#e8d98a`（暖黄白，单像素）

### A3 · 树冠 = 大团叶片体积，不是一棵棵圆球
- 现状缺陷：现在每棵树是独立规整圆团，彼此分离，排一圈像棒棒糖。
- 要求：相邻树冠**连成一片大团**；轮廓不规则、有大有小、高低错落；
  树冠之间允许重叠与咬合。树要够大（参考图树冠直径可达 80–140px @ 640×360）。

### A4 · 树冠边缘用 dither 抖动过渡
- 要求：叶团边缘到背景之间用**有序抖动（Bayer 4×4 或 8×8）**做明暗/有无的渐变带，
  不用硬切，也不用纯随机噪点。抖动带宽度 3–8px。

### A5 · 树冠撒单像素亮点
- 要求：叶团内部朝光面撒**单像素高亮**当透光与落叶，密度低（每棵树几十粒），
  用 A2 的透光色 `#e8d98a` 与点缀橙；朝光方向密、背光方向稀。

### A6 · 地面过渡不规则 + 草边高光
- 现状缺陷：现在土路边缘是平滑渐变，太"圆"。
- 要求：土路/泥土边缘不规则（沿噪声啃出豁口），紧贴路缘一圈 **2–3px 浅黄绿草边高光**
  （比草地亮、偏黄），表现草被踩秃后外圈又冒出的新草。

### A7 · 纵深靠明暗分层，不靠缩小
- 现状缺陷：现在基本靠暗角硬压，层次弱。
- 要求：三段式——**前景**树冠偏暗并压住画面左右/下边缘；
  **中景**最亮（视线焦点）；**远景**带雾、明度拉高、饱和度拉低。
  整体保留暗角，但暗角只是辅助，主体层次靠三段明暗。所有元素缩放仍按 `scene-depth.js`，
  但"远小"只做 0.55–1.15 的辅助，不做主要纵深手段。

### A8 · 氛围粒子
- 要求：空气里漂浮细碎粒子——**小圆环**（半透明描边圆，缓慢漂移/缩放）、
  **光点/孢子**（单像素或 2px，呼吸明暗）、晴天的尘光。
  数量克制（同屏 12–40 粒），只在非雨雪天大量出现。已有 `scene-fx.js` 的萤火/落叶可复用思路，
  但像素视图（canvas）需要自己实现一套，别只靠 SVG 场景那套。

### A9 · 像素粒度（最高优先级，凌驾于其它条款的"好看"之上）
参考图是**硬边像素画**，不是水彩。连续平滑场（metaball、渐变）直接渲染出来就是"软团"，不是像素画。
- **统一逻辑像素**：下面所有尺寸一律指**逻辑像素**（渲染坐标系的 1 单位），
  成图统一最近邻放大显示，不在运行时对单个素材任意缩放。块面按 **PIX=2 网格**量化着色；
  **1px 细节**（叶点、花、颗粒、镂空缝）与 2px 块面可共存于同一逻辑网格——
  块面用 2px 求体积，细节用 1px 求颗粒，两者都是整数逻辑像素，禁止出现亚像素。
- **色阶断层**：每个区域只用 **3–5 个离散色**。同一色档内部是大片完全相同的像素格，
  靠色块拼接出体积，不靠平滑渐变。
- **档间过渡（局部工具）**：Bayer 有序抖动**只用于色档边界与叶团边缘**这条窄带，
  不作为铺满整片区域的全局纹理（大面积 Bayer 格纹会有机械棋盘感）。优先画好叶簇与材质，
  再局部抖动过渡。
- **可读颗粒检验**：把渲染图最近邻放大 4 倍，应看到清晰的同色像素块团，而不是每像素一个色、
  也不是模糊渐变。

### A10 · 风格与时代统一（最高优先级，对齐参考图）
目标观感：**前工业田园**——木屋（原木+石+茅草/木瓦）、土路、木栅栏、野花、野趣的树。
任何现代感/塑料感/霓虹感的东西都不许出现。整体明度偏低、配色沉稳（参考图比当前实现更暗一档）。
- **A10a 树冠 = 碎叶点簇 + 镂空（最重要）**：树冠不是实心圆团。它由大量 **1–2px 的小叶片点**
  密集堆叠成团。**镂空集中在叶团边缘与枝间**（透出背后的暗绿/阴影），**核心体积保留连贯色块**——
  不设全树固定镂空比例硬指标（参考图经压缩无法反推精确比例，均匀撒镂空会像筛网）。
  边缘是叶点逐渐变稀（不是连续色块的轮廓）。远看是一团有体积的树冠，近看是无数小叶点。
- **A10b 橙色秋叶树**：秋季（或常驻）放 1–2 棵**明确的橙色树**（`#c8862e` 一族）做强点缀，
  与绿树对比；其余树保持绿/苔绿。点缀树占比要小（一棵树即可醒目）。
- **A10c 青蓝灌木 + 地被层次**：树下、路边、屋角放**更低更密的灌木丛**，
  其中点缀 1–2 丛**青蓝灌木**（`#3e5a52` 一族）。地被分层：高草 → 矮草 → 灌木 → 树干。
- **A10d 白色/淡黄小花**：草地上撒 1–2px 的白花、淡黄花点（参考图的小野花），
  密度适中、成簇，不要荧光。已有 flower 通道，向"小野花"质感靠。
- **A10e 草地点而非草线**：草地主体是平整的低饱和色块（带明暗分区），上面撒**极细的 1px 草点**
  （不是大丛竖线、不是密集短线）。当前实现草叶偏"毛"，要收敛成更细更稀的"点"。
- **A10f 树干**：细、深棕但有明暗两面，可被树冠半遮；不画成粗黑柱子。

## 工程约束（不可违反）

- 渲染层只读：数据只来自 `/api/state` 的 `settlement` 投影；不发 Command、不碰内核、不推导规则。
- 确定性：同 `(placeId, season, sky, seed)` 必须渲染出**逐像素一致**的图。
  噪声用文件里现有的 `h2/vnoise`（基于坐标的 hash），**禁止** `Math.random()` 进地形/树/粒子位置；
  粒子动画相位可用时间 `t`，但空间分布必须可复现。现有 `GRAIN`/雨滴用了 `Math.random()`，
  属已知历史问题，本次顺手收敛到 hash。
- 性能：640×360，地形/细节/树冠只在场景或季节变化时重建（现有分层已做到）；
  每帧只重画大气与角色。新增粒子/抖动的每帧开销要可控（粒子 ≤ 40，预先算好）。
- 不破坏 `npm test`、`npm run typecheck`、`dev-map-smoke.mjs`。
