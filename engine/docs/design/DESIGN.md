## 0. 一句话

**画卷加话本**：场景是一幅静态插画，叙事文字是主体，其他都是可以收起的抽屉。

## 1. 六条原则

1. **叙事是主角**：阅读区永远在视觉中心，占最大面积。
2. **画面不动、氛围在动**：场景是静态插画，只允许光影、天气、水波、炊烟、火光这类缓慢动效；人物不走动。
3. **隐藏内心，明确手头**：人物内心的精确数值（好感、虔诚、恐惧强度）不显示；
   但玩家**能清点**的东西必须说清——我有几个罐子、交出多少粮、这件事要花多久。
   不全知带来探索欲，不该带来操作困惑。
4. **渐进展开**：一开始只出现用得到的东西；第一次碰到某个系统时，才出现它的入口和一句引导。
5. **词条可以展开**：正文里的概念词、人名、地名都能点开（电脑悬停、手机长按），弹层里的词还能继续点开，最多 3 层。
6. **国风但不堆砌**：纸、墨、木、陶的材质感只用在少数地方（标题、印章、卡片边）。

### 用量规则

- **控制信息优先级，不是控制数字个数。** 赭石色留给当前最该看的一件事；为了形式
  删掉决策必需的信息是本末倒置。
- **原因和成本是两层，不能互相顶掉。** 原因答「为什么做」，成本答「要付出什么」，
  各占一行（见 `settlement.js` 的 `choice-reason` 与 `choice-cost`）。
- **朱砂只用于**：失去、危险、不可撤销的操作。
- 国风元素（祥云、龙纹、金色描边）一屏不超过两处。
- **保证阅读与操作的视觉优先级**：文字可读、按钮可点、当前决定在视野内。
  纸面模式可以用暗文字、留白和对比做到，不必靠整体提亮。
- **一个统一的操作逻辑，允许多个入口**：首页导航和人物上下文可以进入同一功能，
  但进去以后是同一套操作。

## 3. 字体与排版

| 角色 | 字体 |
| --- | --- |
| 标题 | `--serif`（Noto Serif SC / 思源宋体 / 宋体） |
| 正文与界面 | `--sans`（苹方 / 思源黑体 / 微软雅黑） |

叙事正文可以切换宋体（设置里提供「宋体阅读」）。

### 字号阶梯（px）

```
12  注释
14  界面
16  正文（手机）
17  正文（电脑）
20  小标题
24  页标题
32  场景名
44  首页标题
```

### 行高与字距

- 正文行高 **1.75**，界面 **1.5**，标题 **1.3**
- 中文字距 **0.02em**，标题 **0.08em**

### 叙事版心

- 电脑：最宽 **640px**（约 36 个汉字一行）
- 手机：左右各留 **20px**

### 对白格式

```
人名    --ink-2 · 14px · 字重 600 · 单独一行
对白    正文字号 · 不加引号框
```

## 4. 间距、圆角、阴影

**间距阶梯**：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64

**圆角**

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--r-sm` | 8 | 标签 |
| `--r-md` | 12 | 按钮 |
| `--r-lg` | 16 | 卡片 |
| `--r-xl` | 20 | 抽屉、弹层 |
| `--r-pill` | 999 | 标签页、状态胶囊 |

**阴影**：只用 `--shadow-sm`（卡片）、`--shadow-md`（浮层）、`--shadow-lg`（模态框）。

## 5. 断点

| 名称 | 宽度 | 设计稿 | 布局 |
| --- | --- | --- | --- |
| 手机 | < 600 | 390×844 | 底部标签 5 个 |
| 平板竖屏 | 600–899 | — | 按手机布局，版心放宽到 560 |
| 小电脑 | 900–1279 | — | 两栏：中栏 + 右栏，左栏收进抽屉 |
| 电脑 | ≥ 1280 | 1440×900 | 三栏 |

### 常驻入口

- **电脑最多 6 个**：时间与季节、村史、人物、行囊、地图、菜单
- **手机底部 5 个**：此处、人、行囊、村史、我

## 6. 动效

| 类型 | 时长 |
| --- | --- |
| 微交互 | 120ms |
| 面板、抽屉 | 220ms |
| 场景转场 | 600ms（交叉淡入淡出，同时轻微放大 1.02 → 1） |
| 叙事逐段出现 | 每段 180ms 淡入并上移 6px |

**缓动**：`cubic-bezier(.2,.7,.2,1)`

**氛围动效**：只做循环，周期 ≥ 6 秒，透明度变化 ≤ 0.3，不许闪烁。

**`prefers-reduced-motion`**：所有动效改为直接切换，氛围动效停止。

## 7. 组件

| 组件 | 说明 |
| --- | --- |
| **场景舞台 SceneStage** | 三层插画（远、中、近）+ 光照叠加层（按时辰调色）+ 天气层 + 站位点（人物头像牌）+ 物件热点 |
| **人物头像牌 PersonChip** | 3:4 立绘裁切 + 名字 + 表情小标（文字：「在忙」「想跟你说话」「生你气」）；玩家本人加赭石色细边 |
| **叙事块 StoryBeat** | 一段叙述或一句对白；可以带一个小插图 |
| **选项木牌 ChoiceCard** | 木牌质感边框；一行做法 + 一行代价暗示（「会得罪阿石」）；不可选的灰掉并写明原因（「没有界石」） |
| **词条弹层 Glossary** | 标题 + 2–3 句解释 + 相关词条链接；最多叠 3 层，可以固定在侧栏 |
| **抽屉 Drawer** | 电脑从右边滑出，宽 420；手机是底部抽屉，可停半屏或全屏，能下拉关闭 |
| **心事条 ConcernItem** | 图标 + 一句话 + 截止时间（「还有 6 天」） |
| **村史条 ChronicleEntry** | 年份（大号宋体）+ 一句话 + 「为什么」按钮 |
| **印章 Seal** | 只用在三处：当选、立规矩、重大传承；朱砂色，盖章动画 300ms |

## 8. 文案规则

- 界面文字用**当时的说法**：石器村落不说「选举、投票、数据」，说「推、举手、站队、记下」。
- **不出现百分比、点数、进度条数字**；表示程度用「多 / 不少 / 一半 / 不多 / 几乎没有」。
- 按钮用动词开头，**2–4 个字**：「登门」「送礼」「许诺」「当众说」「断这桩事」。

## 9. 禁止事项

- 不要人物行走动画、寻路、帧动画
- 不要游戏化数值面板：血条、经验条、属性雷达图、百分比
- 不要霓虹、玻璃拟态、紫蓝渐变、科技感网格、发光描边
- 不要满屏金色描边、祥云和龙纹
- 不要商城风格：红点轰炸、礼包图标、闪光按钮、倒计时横幅
- 不要把叙事挤到侧边或底部的小框里
- 不要只靠颜色区分状态，必须同时有文字或图标
- 不要用 emoji 当图标；图标统一线宽 1.5px 的线性图标
- 不要引用外部图片地址；插画用占位块并标注尺寸和用途

## 10. 无障碍

- 正文对比度 **≥ 4.5:1**
- 点击区域 **≥ 44×44**
- 所有操作都能用键盘完成，焦点样式用 `--focus`
- 屏幕阅读器：场景插画写 `alt` 描述，叙事区用 `aria-live="polite"`

**地点**：河岸台地（院子、窑边、田、渡口、芦苇荡、议事场）

**人物**：陶叔（52，看火的老人）、陶婶（49）、埴公（61，走过远路）、蓍婆（66，巫医）、阿砺（34，石匠）、阿埴、阿石

- 「陶叔说今年的雨来得早，堤怕是挡不住。」

## 13. 分阶段

| 阶段 | 做什么 | 完成标准 |
| --- | --- | --- |
| **0 设计** | 定稿本规范 + 出四页原型（主场景、对话求票、断事、村史） | 390 和 1440 两个宽度都评审通过 |
| 1 换壳 | Vite + TS + Preact，模拟仍在服务端 | 冒烟测试全过，旧存档能读 |
| 2 去 Node 化 | 模块不再用 `node:fs` 读数据 | 同一套测试在 Node 和浏览器都过 |
| 3 模拟进 Worker | Simulation 在 Worker 里跑 | 断网可玩，快进 20 年保持 60fps |
| 4 打包上架 | PWA / Capacitor / Tauri | 安卓中端机冷启动 < 3 秒 |

**本轮做阶段 0**：规范落地 + 补语义别名与排版令牌 + 建三个核心组件（选项木牌、印章、抽屉）。
