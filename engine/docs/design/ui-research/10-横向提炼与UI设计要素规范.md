# 10 · 横向提炼：UI 设计要素规范 v2（OpenLife · 画卷与话本）

> 来源：32 款游戏逐款拆解（[01](01-桌面模拟类.md)、[02](02-手机与跨端.md)、[03](03-非模拟对照组.md)）+ 4 份行业方法论
> 本文件是 [DESIGN.md](../DESIGN.md) 的**增补与修订**，不推翻既有令牌，只补齐缺失的「透明度 / 融合 / 明度关系 / 融合层 / 状态」规范。
> 所有新增令牌都是**指向已有颜色**的别名，**不新增颜色值**。

---

## 0. 三条硬结论（先看这个）

1. **UI 必须比场景更亮**：腾讯的实测结论是 `特效 ≥ UI > 角色 > 场景`。我们当前的截图里，场景插画（尤其是亮天空 + 落日）比界面亮，导致**标题和顶栏"沉"进画面**。→ 场景整体压暗 6–10%，UI 文字保持高对比。
2. **叙事区不该是"卡片"**：Disco Elysium / 80 Days 的阅读区都不是矩形卡片，而是"文字 + 侧边渐变"。我们的叙事被塞进 `surface` 卡片里，等于给阅读加了一个框。→ 叙事区改"软底"（见 §3.3）。
3. **一屏只留 3 个数字位置**：手机顶栏「时间 / 饥饿 / 地点」三项；其余全部用文字与画面表达。当前截图的「饥饿 0/10 · 今日活动 8/8 格」是四个数字，超预算。

## 1. 颜色系统（增补）

### 1.1 用色预算（吸收腾讯「主色 ≤2 辅助 ≤3」+ 既有"一屏 2 处赭石"）

| 项 | 规则 | 现状 | 动作 |
| --- | --- | --- | --- |
| 色系总数 | 主 2（暮色青绿 `--primary` / 日光赭石 `--accent`）+ 辅助 3（朱砂 `--danger`、成功 `--ok`、中性灰阶） | 已符合 | 保持 |
| 一屏赭石 | ≤2 处 | 未量化 | 加 lint 检查（见 §9） |
| 一屏朱砂 | ≤1 处，且只用于失去/危险/不可逆 | 截图里「饥饿 0/10」是红的，属误用 | 饥饿**未到危险**时用 `--ink-2`，不红 |
| 中性色阶 | ≥5 阶（`--surface` / `--surface-2` / `--surface-3` / `--line` / `--line-strong`） | 5 阶 | 保持 |
| 品质/状态色 | **不新增色相**，用墨色浓淡 + 图形 | 无 | 物品品质：淡墨（普通）/ 中墨（好）/ 赭石描边（罕见） |

### 1.2 语义别名（已有 5 个，再补 4 个）

```css
/* 已有 */
--tone-warm: var(--accent);
--tone-cool: var(--muted);
--tone-hostile: var(--danger);
--ink-speech: var(--ink);
--ink-narration: var(--ink-2);

/* 新增（全部指向已有颜色） */
--ink-name: var(--accent-ink);       /* 人名（无强调色时用 --ink-2） */
--ink-cost: var(--accent-ink);       /* 代价暗示「会得罪阿石」 */
--ink-gain: var(--ok);               /* 收益暗示（少用） */
--ink-why: var(--ink-2);             /* 「为什么」按钮 */
```

### 1.3 明度关系（新增，最关键的修订）

```
场景层   L* ≈ 45–60（压暗后）      ← 最暗
角色层   L* ≈ 55–70
UI 面板   L* ≈ 88–96（亮色）/ 12–20（深色）
UI 文字   L* ≈ 15–25（亮色）/ 88–95（深色）
```

落地方式（CSS，不改美术）：

```css
/* 场景压暗：只在"有 UI 覆盖"的区域轻微压暗，中心保留 */
.scene-backdrop { filter: brightness(.94) saturate(.98); }
/* 顶部信息区背后加一条软渐变，保证文字浮出 */
.topbar::after {
  content: ""; position: absolute; inset: auto 0 -24px 0; height: 24px;
  background: linear-gradient(var(--bg-fade-55), var(--bg-fade-0));
  pointer-events: none;
}
```

**验收**：截取顶栏区域做灰度，UI 文字与背后场景的亮度差 ≥ 25（L*）。

## 2. 字体与排版（增补）

### 2.1 字体角色化（借 Pentiment，降到中文可用的 3 档）

| 角色 | 字体 | 字号 | 说明 |
| --- | --- | --- | --- |
| 叙事（叙述） | `--serif` | `--fs-body` | 「画卷加话本」的"话本" |
| 对白 | `--sans` | `--fs-body` | 与叙述拉开，像"被说出来" |
| 公文/村史/规则 | `--serif` + 字距 .04em | `--fs-ui` | 「奏折」质感 |
| 界面 | `--sans` | `--fs-ui` | 按钮、标签、面板 |
| 印章/章名 | 楷体（系统 `KaiTi, STKaiti`） | `--fs-subhead` | 只用于 3 处（当选/立规/传承） |

> 设置项：**「宋体阅读」开关**（叙述用宋体）；**「统一易读字体」开关**（全部对白也变黑体）——直接对应 Pentiment 的无障碍先例。

### 2.2 字号阶梯（已有 8 档，补充 2 档 → 共 10 档）

```
12  注释（--fs-note）
13  卡片内小字（新增 --fs-fine）      ← 木牌第二行"代价暗示"
14  界面（--fs-ui）
16  正文·手机（--fs-body）
17  正文·电脑（--fs-body-wide）
20  小标题（--fs-subhead）
24  页标题（--fs-title）
28  卡片标题（新增 --fs-card）        ← 人物卡、物品卡
32  场景名（--fs-scene）
44  首页标题（--fs-hero）
```

### 2.3 版心与行数（借 80 Days / Roadwarden / Sunless Sea）

| 端 | 版心 | 单行字数 | 每段句数 | 每屏段数 |
| --- | --- | --- | --- | --- |
| 电脑 | 640px | 36–40 汉字 | 1–3 句 | 2–4 段 |
| 手机 | 屏宽 − 40px | 16–22 汉字 | 1–2 句 | 2–3 段 |

**一次一段、点击推进**（80 Days 的核心）：`StoryBeat` 逐段出现，每段 180ms 淡入 + 上移 6px；点击可立即显示下一段；**玩家可关闭"逐段"改为整页**。

### 2.4 对白格式（补充）

```
名字      14px · 600 · --ink-2 · 单独一行 · 字距 .04em
对白      16/17px · --ink · 行高 1.75
动作      14px · --muted · 斜体不斜（中文用 `<span class="act">（她把碗放下）</span>` 用括号 + --muted）
```

## 3. 透明度与背景融合（本次新增，最重要）

### 3.1 面板透明度档位

| 档位 | 令牌 | 值 | 用在哪 |
| --- | --- | --- | --- |
| 浮层·实 | `--glass-solid` | `rgba(252,250,245,.98)` | 木牌、危险确认（必须完全清楚） |
| 浮层·常 | `--glass` | `rgba(252,250,245,.92)` | 抽屉、面板（已有） |
| 浮层·轻 | `--glass-soft`（新增） | `rgba(252,250,245,.82)` | 叙事软底、常驻小条 |
| 遮罩 | `--scrim` | `rgba(24,34,30,.42)` | 模态背后（已有） |
| 遮罩·重 | `--scrim-deep`（新增） | `rgba(24,34,30,.58)` | 全屏选择（三选一） |

**规则**：所有浮层透明度 **≥0.82**；低于此值只在"背后是纯色"时允许。

### 3.2 融合手法（六种，按使用频率排序）

1. **边缘渐隐接地**（Victoria 3）：面板朝向场景的一侧加 24px 渐变到透明。
   ```css
   .drawer::after { /* 底部抽屉顶端 */
     content:""; position:absolute; top:-24px; left:0; right:0; height:24px;
     background: linear-gradient(var(--bg-fade-0), var(--glass));
   }
   ```
2. **侧边软渐变**（Disco Elysium）：叙事区不做卡片，用两侧 40px 渐变把文字"托"在场景上。
3. **遮罩压暗而非替换**（Genshin/江南百景图）：打开抽屉时 `scene { filter: brightness(.72) }`，场景不消失。
4. **纸纹叠加**（明日方舟的噪点底纹）：全局一张 2–3% 不透明度的纸纹，`mix-blend-mode: multiply`。
5. **暗角**（Dwarf Fortress）：场景舞台 `radial-gradient` 压边，把视线收到中心。
6. **毛玻璃（慎用）**：只在"面板背后仍有场景且要保留层次"时用 `backdrop-filter: blur(10px)`；**手机低端机禁用**（用半透明替代）。

### 3.3 叙事区「软底」规范（替代卡片）

```
背景：linear-gradient(180deg, var(--bg-fade-0) 0%, var(--bg-fade-55) 12%, var(--bg-fade-55) 88%, var(--bg-fade-0) 100%)
左右：各 40px 横向渐变到透明（classic "vignette 文字"）
圆角：0（软底不画圆角）
```

**为什么**：卡片会给阅读加"边框"，而阅读应当是"浮在画上的一段话"。

### 3.4 深色模式

- 已有的 dark 段沿用；新增：**场景在深色下 `brightness(.82)` 已存在**，再补 `saturate(.95)`（已存在）。
- 深色下面板透明度可降到 0.9（深底更宽容）。
- **夜晚自动切换**（借 Against the Storm）：游戏内时辰为夜 → `data-theme="dark"`，过渡 800ms。

## 4. 层次与投影（增补）

| 层级 | 表达 | 规则 |
| --- | --- | --- |
| L0 场景 | 无 | — |
| L1 常驻条 | 无底板 + 渐隐 | 只加 1px 文字描边 `rgba(35,47,42,.28)` |
| L2 软底叙事 | 上 §3.3 | 无阴影 |
| L3 抽屉/面板 | `--glass` + `--shadow-md` | 阴影方向统一"向上/向右" |
| L4 木牌/模态 | `--glass-solid` + `--shadow-lg` + `--scrim` | 一次只允许一层 |
| L5 词条弹层 | 内层缩进 8px、阴影减一档 | 最多 3 层（已有） |

**投影规范**：`--shadow-sm/md/lg` 已存在；新增规则——**同一屏只出现两个层级的阴影**。

## 5. 间距与尺寸（增补）

- 间距阶梯（已有）：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 → **补 2（图标与文字间距）**
- **外边距 > 内边距**（腾讯）：卡片外间距应大于卡片内边距，否则"糊成一片"
- 屏幕安全边距：手机 20px；电脑 ≥32px；**内容区离屏幕边缘 ≥55px**（腾讯实测值，适合大屏）
- 触控热区：≥48×48（手机）、≥44×44（电脑鼠标目标）
- 卡片比例：人物卡 3:4；物品卡 1:1；事件木牌 5:3（借原神/星铁的卡片比例稳定性）

## 6. 组件规范（补 6 个缺失组件）

### 6.1 常驻信息条 TopInfoBar（新增）
- 内容：日期/时辰（左）、当前地点（中）、饥饿或最紧要的一项（右）
- 形式：**无底板**，文字 + 图标 20px；背后 24px 渐隐
- 手机高度 44；电脑高度 48 + 底边 1px `--line`

### 6.2 叙事软底 StoryBeatSoft（替代现有卡片）
- 见 §3.3
- 段落之间 16px；第一段与顶部留 24px

### 6.3 选项木牌 ChoiceCard（补状态）
```
默认：--glass-solid + --shadow-sm + 1px --line
悬停(电脑)：translateY(-1px) + --shadow-md，120ms
按下：translateY(0) + inner shadow 1px，80ms
禁用：opacity .55 + 文字 --muted + 原因行（--fs-fine）
危险：左侧 3px --danger 竖条（不是整块变红）
```
- 结构固定三行：**做什么（16px）／代价暗示（13px · --ink-cost）／不可选原因（13px · --muted）**

### 6.4 底部抽屉 BottomSheet（补手势规范）
- 三档高度：**peek 96px / half 52vh / full 90vh**
- 拖拽阈值：位移 >25% 或速度 >0.5px/ms 才切换档
- 顶部 40×4 圆角把手（`--line-strong`）
- 打开时场景 `brightness(.72)`，关回恢复（220ms）

### 6.5 印章 Seal（补动画与三处限制）
- 出现：从 1.2 倍缩到 1 + 轻微旋转 −3°，300ms，`--ease-soft`
- 出现后 2s 内不重复盖章
- 只用于：当选 / 立规矩 / 重大传承

### 6.6 词条弹层 Glossary（补视觉层级）
- 每层：缩进 8px、边框从 `--line` 到 `--line-strong` 递减
- 第 3 层不再可点（文字变 `--ink-2`）
- 手机：长按 240ms 触发，松手 1.2s 后消失（可钉住）

## 7. 动效规范（增补语义表）

| 场景 | 时长 | 缓动 | 说明 |
| --- | --- | --- | --- |
| 按钮按下 | 80ms | ease-out | 只做位移/内阴影 |
| 悬停 | 120ms | `--ease-soft` | 位移 ≤2px |
| 抽屉 / 面板 | 220ms | `--ease-soft` | 位移 + 淡入 |
| 叙事逐段 | 180ms | `--ease-soft` | 淡入 + 上移 6px |
| 场景转场 | 600ms | `--ease-soft` | 交叉淡入 + 1.02→1 缩放 |
| 系统切换（跳页） | 320ms | ease-in | 深色淡出（明日方舟做法） |
| 有逻辑关联（升级/合成） | 240ms | `--ease-soft` | zoom 1.02→1 + 淡入 |
| 印章 | 300ms | 回弹 | 1.2→1 + −3° |
| 大事件（灾/季节） | 1200ms | ease-in-out | 整屏降饱和 0.2 + 薄雾层 |
| 氛围循环 | ≥6s | linear/ease-in-out | 透明度 ≤0.3 |

**禁止**：循环闪烁、>3 个元素同时动、界面元素周期性跳动。

## 9. 一致性检查清单（可脚本化）

### 9.1 视觉一致性（人工走查，每页 60 秒）
1. 一屏内**赭石出现 ≤2 处**？（用取色器数）
2. 一屏内**朱砂 ≤1 处**且语义正确？
3. 所有图标**同线宽（1.5px）、同朝向、同光源**？
4. 阴影只有 **2 个层级**？
5. 圆角只有 **4 档**（8/12/16/20）+ pill？
6. 字号是否**全在阶梯内**（无 15px、22px 这类野值）？
7. 行距是否**只有 3 档**（1.3/1.5/1.75）？
8. 面板透明度是否**只有 3 档**（.98/.92/.82）？

### 9.2 可脚本化的 5 条（建议加入 CI）
```bash
# 1. 禁止野字号
rg -n 'font-size:\s*\d+px' apps/web/public/*.css | rg -v '\b(2|7|8|12|13|14|16|17|20|24|28|32|44|48|64|80)px' && echo "野字号!"
# 2. 禁止新色值（只允许主题令牌）
rg -n '#[0-9a-fA-F]{3,8}' apps/web/public/*.css | rg -v 'theme.css' | rg -v 'rgba?\(' | head
# 3. 禁止纯黑纯白
rg -n '#000\b|#fff\b' apps/web/public/*.css
# 4. 禁止未走令牌的模糊
rg -n 'backdrop-filter' apps/web/public/*.css
# 5. 禁止无限动画
rg -n 'animation:.*infinite' apps/web/public/*.css
```

- 200% 字号下：确认按钮与返回可见
