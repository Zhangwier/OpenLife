# 03 · C 组：非模拟类优秀 UI 对照组（9 款）

> 这一组不是"玩法参考"，而是**界面的极致做法参考**：文字游戏、排版、隐喻、转场、可读性。
> 原则：只借手法，不借题材。

---

## C01 · Pentiment 隐迹渐现（PC/Xbox｜历史叙事｜2022）

**一句话**：**字体就是配音**——5 套自定义字体代表不同身份、教育程度与语气。

- **屏幕清单**：场景（2D 插画 + 人物）、对话（手写体文本框）、调查/推理板、地图、日程、书籍阅读、结局。
- **L1 信息架构**：**没有"菜单"感**；一切通过"点击场景中的人/物"触发；只有 1 个"日记/日程"入口。
- **L2 布局**：对话占**屏幕下方约 35%**，人物在场景中央；选项用**手写体分行排列**在对话下方。
- **L3 颜色**：**羊皮纸米黄 + 墨黑 + 少量朱红**（与 OpenLife 几乎同源）。
- **L4 字体**：**5 套自定义字体**（Scribe Script / Humanist Script / Monastic Script / Printer Type / Peasant Script），共 2700+ 字形；**每套都有 3–4 个字形变体**模拟手写的不一致；**无障碍设置可强制全部用最易读的 Humanist Script**。
- **L5 透明度与融合**：文本框**不是矩形框**，而是"墨迹晕开的纸片"；边缘不规则；**逐字写出（逐笔画）**，速度可调。
- **L6 动效**：文字**逐字/逐笔画写出**；场景切换是"翻书页"。
- **L7**：**无障碍选项允许统一字体**（极重要的先例）；字号可调；对比度高。
- **可迁移做法**
  1. **字体角色化**：叙述=宋体，村民口述=略带手写的宋/楷，头人/公文=端正宋，外乡人=另一样（→ 我们只有 2 套字体，可先做"正文宋体 / 对白黑体 / 公文楷体"三档）。
  2. **逐字出现 + 可调速 + 点击加速**（→ `StoryBeat`）。
  3. **不规则的文本框**（→ `StoryBeat` 的纸片容器）。
  4. **提供"统一易读字体"开关**（→ 无障碍设置：宋体阅读 / 全部黑体）。
- **不学什么**：中文字体不能用历史手写体（可读性），只在"印章/标题"上做古意。

> 参考：[Lettermatic · Pentiment 字体案例](https://lettermatic.com/custom/pentiment)、[Josh Sawyer 访谈（SHARP News）](https://sharpweb.org/sharpnews/2022/12/07/pentiment-an-interview-with-josh-sawyer/)

## C02 · 80 Days（手机/PC｜互动小说｜2014）

**一句话**：**"点一下才出下一段"**——节奏本身是界面。

- **屏幕清单**：地图（环球路线）、城市（可去之处列表）、旅途（文字段）、对话（选项）、物品/财务、结算。
- **L1 信息架构**：4 个常驻按钮（地图/背包/人/日志）；层级 2 层。
- **L2 布局**：**文字占据约 60% 屏幕**，段落之间有较大留白；选项是**短句列表**，不是按钮。
- **L3 颜色**：**旅行箱/旧地图的土黄 + 深绿**；几乎无彩色。
- **L4 字体**：**衬线正文（Georgia 类）**，字号大，行距宽；**标题用装饰大写**。
- **L5 透明度与融合**：**无面板**——文字直接排在背景上，背景是低对比的城市剪影/地图。
- **L6 动效**：段落**淡入 + 上移 8px**，一次一段；**"点一下"是核心交互**（玩家自己把故事拉出来）。
- **L7**：手机版字号大、行距宽；点击一次一段，阅读节奏由玩家控制。
- **可迁移做法**
  1. **一次一段 + 点击推进**（→ 我们的 `StoryBeat` 已经是这个方向，可明确写进规范）。
  2. **选项写成"短句"而不是按钮**，但仍给出可点区域（→ 选项木牌的文字部分）。
  3. **文字直接压在背景上 + 局部增加不透明度**（→ 叙事区可以做"文字背后一块 0.55 的软渐变"，而不是整块卡片）。
- **不学什么**：几乎无 UI 图标的极简（我们需要更多可见操作）。

## C03 · Reigns 王权（手机/PC｜卡牌决策｜2016）

**一句话**：**一张卡 = 一个两难**；用**滑动手势**代替按钮。

- **屏幕清单**：卡牌（主）、四资源图标（顶部）、结算（朝代结束）、成就。
- **L1 信息架构**：**只有一屏**；没有菜单、没有列表。
- **L2 布局**：卡牌占屏幕 80%；**顶部 4 个资源图标**（教会/人民/军队/国库），**没有任何数字**，只有图标的"表情"变化。
- **L3 颜色**：**单色插画 + 红/金点缀**；资源图标颜色只在"危险"时变红。
- **L4 字体**：**衬线 + 手写感**；卡片上文字居中，字号大。
- **L5 透明度与融合**：卡片不透明，但**卡片边缘是撕裂的羊皮纸**；背景是模糊的纹样。
- **L6 动效**：**滑动时卡片倾斜 + 旋转（±15°）**；松手后飞出；资源图标在变化时**轻微抖动**（暗示，不显示数字）。
- **L7**：极简单手势；文字大；但对快速滑动有误触风险（社区反馈）。
- **可迁移做法**
  1. **"不显示数字"的极端样本**：资源只用图标表情（→ 我们的"民心"用一句话 + 图标，可参考其"图标情绪化"）。
  2. **卡片倾斜 + 飞出**（→ 木牌选择可以左右轻推表示倾向）。
  3. **暗示型反馈**：顾问生气时图标"闪一下"（→ 人物的态度用头像牌微弱明暗变化，1 次 300ms）。
  4. **一屏一决策**（→ 求票/断事做成全屏单卡）。
- **不学什么**：滑动作为唯一交互（无障碍不允许，需保留按钮替代）。

## C04 · Roadwarden 路卫（PC/Mac｜文字 RPG｜2022）

**一句话**：**文字优先**的界面设计——把"阅读体验"当成 UI 的全部。

- **屏幕清单**：地图（手绘）、场景描述（文字）、对话、背包、日记、时间/精力、商人。
- **L1 信息架构**：地图是主界面（手绘区域图），点区域进入文字场景；左侧常驻"时间/精力/背包"。
- **L2 布局**：**文字区占 60–70%**；**左侧一条窄栏**（图标 + 数字 + 状态），右侧偶尔插图。
- **L3 颜色**：**单色墨绿/棕 + 米白**；几乎只用 2 色。
- **L4 字体**：**等宽/打字机感字体？不——是衬线 + 可切换字体**（官方提供了字体选择，社区要求后加入）；正文大、行距宽。
- **L5 透明度与融合**：文字**直接压在米白纸底**，无卡片；**可切换"低对比/高对比"**。
- **L6 动效**：几乎没有；文字直接刷新。
- **L7**：**提供字体选择**（社区推动）；可调字号；阅读节奏稳定。
- **可迁移做法**
  1. **左窄栏 + 右大文字区**（→ 电脑三栏的"中栏叙事 + 右栏状态"原型）。
  2. **字体可切换（社区驱动）**（→ 我们的"宋体阅读"设置）。
  3. **单色墨绿/棕**（→ 验证我们 `--ink #232f2a` 的方向正确）。

> 参考：[Jay McGavren 的 Roadwarden 设计分析](https://jay.mcgavren.com/2023/02/22/roadwarden-game-design-analysis.html)

## C05 · Sunless Sea / Fallen London（PC/手机｜文字冒险｜2015）

**一句话**：**"故事卡" + "质量图标"**——用图标表示角色属性与资源，用文字讲一切。

- **屏幕清单**：海图、港口（故事列表）、故事卡（一段文字 + 选项）、船员/船、日志、商店。
- **L1 信息架构**：港口是"故事列表"；每个故事点击后展开为卡片。
- **L2 布局**：**故事卡居中**，宽约 640px；选项在卡下方；左侧是"质量"图标列。
- **L3 颜色**：**墨黑深底 + 琥珀/金强调**（暗黑维多利亚）；文字为米白。
- **L4 字体**：**衬线 + 手写装饰**；正文字号中等但行距大。
- **L5 透明度与融合**：故事卡是**深色半透明纸（0.9）**，边缘有金色细框；背后是海图的模糊。
- **L6 动效**：故事卡切换 200ms 淡入；**文字逐句显现**（可选）。
- **L7**：文字偏小（批评点）；有"更大字体"选项。
- **可迁移做法**
  1. **居中 640 故事卡**（与我们的版心一致）。
  2. **"质量"图标列**（→ 人物页的"手艺/禀赋"用图标 + 文字，而不是数字）。
  3. **深底 + 单色强调**（→ 夜间模式参考）。

## C06 · Disco Elysium 极乐迪斯科（PC/主机｜叙事 RPG｜2019）

**一句话**：**"技能即声音"**——技能不是数值，是在对话里插话的角色。

- **屏幕清单**：场景（等距）、对话（右侧大文本框 + 左侧立绘）、技能检定、思维阁（Thought Cabinet）、物品栏、地图、角色面板。
- **L1 信息架构**：**对话框是主界面**；技能检定弹窗嵌在对话中；思维阁全屏。
- **L2 布局**：**右侧 45% 是对话**，左侧是立绘与场景；**选项按"声音"分组**（逻辑、共情、权威…）。
- **L3 颜色**：**水彩油画感 + 低饱和**；界面用**深色半透明 + 暖色文字**。
- **L4 字体**：**衬线正文 + 装饰大写标题**；字号大（阅读舒适）。
- **L5 透明度与融合**：对话框是**半透明深色（0.82–0.88）覆盖在场景右半**，没有边框，**只靠渐变过渡**；这是"融合"的高阶做法。
- **L6 动效**：对话文字**逐字出现**；选项出现有轻微上浮；检定失败时**屏幕轻微震动**（meta）。
- **L7**：文字大小适中；无读屏；对比度一般（批评点，我们不要低于 4.5:1）。
- **可迁移做法**
  1. **无边框半透明文字区 + 侧边渐变**（→ 叙事区可以去掉卡片，用"侧边渐变遮罩"）。
  2. **"声音分组"的选项**：每个选项前标出"谁在说"（→ 我们的求票/断事：每个做法前标出"谁受益/谁不满"）。
  3. **失败反馈的轻微震动**（→ meta UI，慎用，1 次 200ms）。
- **不学什么**：低对比；过暗。

## C07 · Persona 5 Royal 女神异闻录 5 皇家版（主机/PC｜RPG｜2020）

**一句话**：**界面就是美术风格**——红黑 + 撕纸 + 斜切，全屏都在动。

- **屏幕清单**：战斗、菜单、日常地图、社群（好感）、日历、结局。
- **L1 信息架构**：**菜单本身是一场演出**；层级 3 层。
- **L2 布局**：**非正交布局**（斜切、错位、重叠），打破栅格。
- **L3 颜色**：**红 + 黑 + 白**（仅 2 色系，极高对比）。
- **L4 字体**：**粗描边手写/漫画字体** + 衬线混排；文字经常倾斜。
- **L5 透明度与融合**：**撕纸边缘 + 实色块**，几乎没有渐变；**界面元素会"切进"画面**。
- **L6 动效**：**所有切换都是"甩"进来的**（150–300ms，带旋转/缩放），有强烈的"弹"感。
- **L7**：动效太多可能引发不适（有"减少动效"选项）；文字对比极强。
- **可迁移做法**
  1. **2 色系 + 高对比**（→ 证明我们的"青绿 + 赭石"可以撑起全套界面）。
  2. **斜切/错位**（谨慎借用：纸片可以 1–2° 旋转，模拟"手工摆放"）。
  3. **"减少动效"必须存在**（→ 已有）。
- **不学什么**：高频强动效（我们"氛围在动"，不是"界面在跳"）。

## C08 · A Short Hike 短途旅行（PC/Switch｜探索｜2019）

**一句话**：**没有 HUD**——用"世界里的物件"告诉你要去哪。

- **屏幕清单**：世界（无 HUD）、地图（一张纸质地图）、对话（底部小框）、成就。
- **L1 信息架构**：只有 1 个"地图"键 + 对话。
- **L2 布局**：UI 占屏 <5%。
- **L3 颜色**：**低多边形 + 柔和渐变**，界面纯白细字。
- **L4 字体**：**像素/小号无衬线**，仅用于对话与提示。
- **L5 透明度与融合**：**纯白文字 + 轻投影**，无底板。
- **L6 动效**：对话文字逐字；世界里有鸟、风、落叶在动（**氛围动效教科书**）。
- **L7**：可开关"帮助提示"。
- **可迁移做法**
  1. **"世界即提示"**：让场景本身携带信息（→ 粮食少了，仓里的粟堆变矮）。
  2. **氛围动效的分层**（近景落叶、中景炊烟、远景云）→ 我们的 `scene-fx.js` 可以按深度分层。

## C09 · Chicory: A Colorful Tale 菊苣：五彩斑斓的故事（PC/PS｜冒险｜2021）

**一句话**：**"画笔"就是界面**——玩家用画笔给世界和 UI 上色。

- **屏幕清单**：世界、画笔工具轮（长按呼出）、对话（底部）、地图（可涂色）、收藏。
- **L1 信息架构**：工具轮是唯一常驻交互；对话自动推进。
- **L2 布局**：**工具轮围绕光标/摇杆展开**（径向菜单）。
- **L3 颜色**：**黑白线稿世界 + 玩家涂上的颜色**——"颜色是奖励"。
- **L4 字体**：手写漫画字体。
- **L5 透明度**：对话框为**白色纸片 + 黑边**，简单但清晰。
- **L6 动效**：笔刷涂抹即时反馈；对话 150ms 淡入。
- **L7**：径向菜单对精细操作要求高（无障碍风险）。
- **可迁移做法**
  1. **径向/环形菜单**（→ 手机"做事"可以做成以人物为中心的环形选项，但必须同时提供列表）。
  2. **颜色作为叙事奖励**（→ 世界随玩家的行为"变暖"，例如村子繁荣后场景色调变暖 5%）。
  3. **纸片对话框 + 黑边**（→ 叙事卡片的"硬边"变体）。

## C 组小结

| 手法 | 来源 | 对我们的价值 |
| --- | --- | --- |
| 字体角色化 + 无障碍统一字体 | Pentiment | ★★★ 直接决定"文字游戏"的质感 |
| 一次一段 + 点击推进 | 80 Days | ★★★ 阅读节奏 |
| 不显示数字 + 图标情绪化 | Reigns | ★★★ 与我们的"不给看数字"完全一致 |
| 大文字区 + 窄状态栏 | Roadwarden | ★★★ 电脑三栏比例参考 |
| 居中 640 故事卡 | Sunless Sea | ★★ 版心 |
| 无边框半透明文字区 | Disco Elysium | ★★★ 本报告的「融合」核心 |
| 2 色系高对比 | Persona 5 | ★★ 色板校验 |
| 世界即提示 + 氛围分层 | A Short Hike | ★★★ 我们的场景舞台 |
| 颜色作为奖励 | Chicory | ★★ 长期体验 |

## 附：行业方法论（4 份）

### M1 · Game Accessibility Guidelines（全量清单）
可直接落地的条目（Basic 级）：
- 提供游戏速度调节；触控元素大且间距足；UI 与玩法同一输入方式可达
- 避免闪烁与重复图案；文本节奏由玩家控制；简单清晰的语言与格式；易读的默认字号
- 文本/UI 与背景高对比；**任何信息不只靠颜色**；不把关键临时信息放在视线外
- 字幕清晰、可调、说话者标识；设置全部可保存

（来源：[Full list – Game Accessibility Guidelines](https://gameaccessibilityguidelines.com/full-list/)）

### M2 · Diegetic UI 四分类（Marcus Andrews / Dead Space 分析）
- **Diegetic（画内）**：世界内、角色可见（以撒脊柱血条）
- **Non-diegetic（画外）**：只在屏幕（角落血条）
- **Spatial（空间）**：在世界 3D 空间、但角色看不见（任务标记）
- **Meta（元）**：属于故事、但不在物理空间（受伤时屏幕血渍）

对我们的用法：**叙事 = 画内（文字是"这里的人说的话"）；常驻状态 = 画外但极简；氛围 = 元（界面被执行世界的天气侵蚀）**。

（来源：[Punchev · Diegetic vs Non-Diegetic UI](https://punchev.com/blog/diegetic-vs-non-diegetic-game-ui)）

### M3 · 腾讯《无限法则》UI 设计原则（15 条 + 图标 5 统一）
可迁移的关键：
- **低信息干扰**：网页真正被读的文字不足 20%，局内 UI 只留最重要的常显
- **让步原则**：UI 不抢场景戏份
- **明度关系：特效 ≥ UI > 角色 > 场景**
- **颜色数量**：主色 ≤2 色系，辅助 ≤3 色系
- **边距统一**（从 30px 调到 55px）；**外边距 > 内边距**
- **信息块面化**：相近元素靠近成组
- **避免居中**（除非正式庄重）
- **图标 5 统一**：朝向、透视、视觉重量、光源方向、光源冷暖
- **品牌感**：造型元素 + 颜色，贯穿所有出口

（来源：[腾讯游戏学堂 · 无限法则背后的UI设计原则](http://gameinstitute.qq.com/knowledge/100097)）

### M4 · 动森字体排版分析（中文排版视角）
- 圆体的**字面小、笔画均匀**，在低分辨率下仍有高辨识度
- **正文与交互提示必须分档**，不能把所有文字做成同一种"可爱"
- 大段文本需要**更宽行距**（中文 ≥1.6）
- 字体必须与 UI 造型（圆角）同代，否则"字体与界面打架"
