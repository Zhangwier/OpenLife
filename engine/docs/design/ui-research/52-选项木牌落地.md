# 52 · 选项木牌落地（2026-10-18 第三轮）

> 前两轮见 [50 本轮UI改造记录](50-本轮UI改造记录.md)、[51 重复入口与失效开关修复](51-重复入口与失效开关修复.md)。
> 我选了「木牌」先做，理由在文末。

---

## 为什么先做这个

「此刻」页里点一个人、点一件东西，出来的那组选项是**玩得最频繁的一处**——每次交互都要看它。而它当时的样子是：

- 图标 + 标题 + 「3 格活动」挤在一行，中文一长就换行错位；
- **`hint` 字段一直存在，但从来没被渲染过**——世界明明写了「陶婶正缺这个，送出去就是对方的了」，
  玩家只看到「3 格活动」，等于只告诉他要付多少，不告诉他为什么值得做；
- 外面还套着一层浅色卡片，卡片里每个选项又是一张卡：两层框、两层底、两层圆角。

---

## 改了什么

### 1. 三行固定结构

`settlement.js` 的 `btn()` 重写：

```html
<button class="choice-card is-primary">
  <span class="choice-label"><svg/>叫住这个人，问一句</span>
  <span class="choice-cost is-reason">当面交流后逐渐相识；搭一次话不会直接成为朋友。</span>
  <span class="choice-blocker">需要：界石</span>          <!-- 仅禁用时出现 -->
</button>
```

| 行 | 内容 | 字号 / 颜色 |
| --- | --- | --- |
| 一 | 做什么（动词开头） | 16px / 600 / 图标 19px |
| 二 | 代价暗示：优先用世界的 `hint`，没有才退回时间成本 | 13px / `--accent-ink`（有 hint）或 `--muted` |
| 三 | 做不到的原因 | 13px / `--ink-2` |

**代价说人话**：不再显示「3 格活动」，而是

- 1–2 格 → 「一小会儿」
- 3–4 格 → 「小半天」
- >4 格 → 「大半天」
- 跨天 → 「要过一夜」「要过 N 夜」
- 都不占 → 「随手就做」

只有当世界给了 `hint` 时才显示 `hint` —— 那是真实原因，比时间成本更值得读。

### 2. 五种状态

| 状态 | 表现 |
| --- | --- |
| 默认 | `--surface` 底 + 1px `--line` + 左侧 3px 中性边 |
| 悬停 | 底升一档，左侧边变青绿 |
| 按下 | `translateY(1px)`，80ms |
| 主推 | **只点亮左侧那道边**，不整块变色（一屏赭石仍只有 2 处） |
| 禁用 | 底降一档、字变灰，**但不降透明度**（深色下会读不出），第三行写原因 |

### 3. 去掉一层框

`.scene-quick-actions` 从"浅色卡片"改成"标题 + 一条分隔线"，视觉重量全部落到木牌上。
关闭按钮也从中性方钮改成无底图标钮——它不该和选项抢注意力。

### 4. 两个类名统一外观

`.scene-quick-choice` 是旧类名（行囊详情、职位面板还在用）。没有另写一套样式，而是让它继承木牌骨架；
否则同一屏里会出现两种"选项"：一种是木牌（左侧细边），一种是方框（四边框 + 虚底），像两套设计。

### 5. 清理重复定义

`scene.css` 里原有一份 `.choice-card`（第一版木牌）。`theme.css` 现在也有一份，两者同名不同样。
删掉 `scene.css` 那份，只留一条注释指回去——**同名类只能有一处定义**。

## 仍未显示的一层：谁受益 / 谁不满

调研里（Disco Elysium / CK3）木牌最有力的一行是"谁在说"或"谁会不满"。现在**做不到**，因为动作数据里没有这个字段：

```
actions: { id, label, hint, days, enabled, reason, payload, activityCost }
```

要做需要模块侧提供"这条命令会影响谁"的投影。这属于改世界接口，不是改样式，所以留在下一步；
现在第二行用 `hint` 兜底，已经是现有数据能给出的最有信息量的内容。

## 下一步建议顺序

3. **阴影 23 → 3+1**：主要在 `stage.css` 场景美术层，需要美术判断哪些阴影是必要的
4. **9 张场景真插画**：占位图已可按图施工（`scene-placeholder.js` 里就是分层取景说明）
