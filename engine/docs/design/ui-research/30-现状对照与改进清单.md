## 2. 三个必须马上处理的问题

### P0-1 · HUD 违反了自家规范

截图 `artifacts/mobile-ui/ux-390px-scene.png` 顶部显示：

```
饥饿 0/10 · 今日活动 8/8 格
```

这同时违反三条既有规范：
- 「不给玩家看数字」
- 「不出现百分比、点数、进度条数字」
- 「一屏赭石 ≤2 处」（此处红色被用于普通状态）

代码侧对应 `.hud-item` + `.hud-track` + `.hud-pips` + `.hud-item.warn`。

**改法**（不需改数据层，只改投影文案）：
| 现在 | 改成 |
| --- | --- |
| `饥饿 0/10` + 红条 | 「肚子空着」/「吃过一顿」/「还撑得住」三档文字 + 一个 12px 图标 |
| `今日活动 8/8 格` | 「今天还能做两件事」/「今天做不动了」 |
| 红色 | 只在"真饿到危险"时出现，且一屏至多 1 处 |

### P0-2 · 叙事被关在卡片里

`.hearth-story` 位于 `section.panel` 内，阅读区因此有一个 1px 边框 + 圆角 + 阴影。而对照的 4 款文字游戏（Pentiment / 80 Days / Disco Elysium / Sunless Sea）**没有一款**把叙事放进带边框的卡片。

**改法**：新增 `StoryBeatSoft`（规范 §3.3），把叙事从 `.panel` 里拿出来，改为上下渐隐的软底。工作量小（一个 class + 一段 gradient），视觉收益最大。

### P0-3 · UI 比场景暗，标题"沉"进画面

截图里天空与落日是全画面最亮处（L* 约 70+），而顶栏文字是 `--ink-2`（L* 约 40）。腾讯的实测结论是 `特效 ≥ UI > 角色 > 场景`，我们正好相反。

**改法**：
```css
.scene-backdrop { filter: brightness(.94) saturate(.98); }   /* 常亮也压一点 */
.topbar::after { /* 24px 渐隐，让文字浮出 */ }
```
并在 390 / 1280 两档截图做灰度对比，要求文字与背后场景亮度差 ≥25。

## 3. 设计令牌落地差距（可量化）

### 3.1 字号：214 条声明 vs 10 档阶梯

```text
9px×2  10px×7  11px×16  12px×49  13px×55  14px×37  15px×14
16px×7  17px×2  18px×3  20px×2  21px×1  22px×5  24px×8
27px×1  28px×3  40px×2
```

问题不在"多"，而在**同一种语义用了不同字号**：
- 注释：11 / 12 / 13 三种都在用
- 卡片标题：14 / 15 / 16 三种
- 页标题：22 / 24 / 28 三种

**改法（分三步，不要一次全改）**
1. 先建立映射表：`9→12`、`10→12`、`11→12`（卡片内小字用新增的 `13`）、`15→14`、`18→20`、`21→20`、`22→24`、`27→28`。
2. 再用 codemod 批量替换 `font-size: 13px` → `font-size: var(--fs-ui)`。
3. 最后加 CI 检查（见 §5），防止回潮。

### 3.2 阴影 24 种 → 3 种

```bash
# 复现
Get-Content apps/web/public/*.css -Raw | Select-String -Pattern 'box-shadow:\s*([^;}]*)' -AllMatches
```
24 种阴影意味着"层级语言"无法被玩家学习。**改法**：保留 `--shadow-sm/md/lg`，其余全部就近映射；`stage.css` 里为场景元素写的柔和阴影可归入新令牌 `--shadow-scene`（作为第 4 个，仅场景用）。

### 3.3 圆角：令牌 + 7 种硬编码

| 硬编码值 | 出现 | 建议 |
| --- | --- | --- |
| 6px | 8 | → `--r-sm`(8) 或新增 `--r-xs`(6) |
| 10px | 3 | → `--r-md`(12) |
| 12px | 6 | → `--r-md` |
| 16px | 3 | → `--r-lg` |
| 30px | 3 | → `--r-pill` |
| 42px / 3px / 4px | 2/3/2 | 逐个判断（42 可能是头像） |

### 3.4 透明度：13 种 → 5 档

| 现有值 | 用途 | 归入 |
| --- | --- | --- |
| .92 .9 | 面板 | `--glass` |
| .85 .8 | 轻浮层 | `--glass-soft` |
| .55 .6 | 渐隐 | `--bg-fade-55` |
| .35 .3 | 遮罩/描边 | `--scrim` / 文字描边 |
| .28 .08 .05 | 描边/纸纹 | 新 `--hairline` |

### 3.5 图标线宽不一致（文档 vs 代码）

`icons.js` 第 1 行注释：`24 grid, 1.8 stroke, round caps`；而 `DESIGN.md` 第 9 节写「图标统一线宽 1.5px」。二者必须统一——**建议以代码为准改文档（1.8 在小尺寸下更清楚），或统一降到 1.6 并全局替换。**

## 5. 可直接加进 CI 的 5 条检查

```bash
# 1) 禁止阶梯外的字号
rg -n 'font-size:\s*\d+px' apps/web/public/*.css \
  | rg -v ':(12|13|14|16|17|20|24|28|32|40|44)px'

# 2) 非 theme.css 禁止硬编码颜色
rg -n '#[0-9a-fA-F]{3,8}' apps/web/public/*.css | rg -v 'theme.css' | rg -v 'stage\.css' | head

# 3) 禁止纯黑纯白
rg -n '#000\b|#fff\b' apps/web/public/*.css

# 4) 阴影只能来自令牌
rg -n 'box-shadow:\s*(?!var\()' apps/web/public/*.css

# 5) 模糊值只能是 6/10
rg -n 'backdrop-filter:\s*blur\((\d+)px\)' apps/web/public/*.css | rg -v 'blur\((6|10)px\)'
```

> 注：`rg` 的负向断言在部分版本需 `--pcre2`。Windows 上可用 `pwsh` 版等价脚本，已在 §1 复现命令里给出写法。

## 6. 分阶段改进路线（含验收）

### 阶段 A：一周内可完成（纯 CSS + 文案）
1. 叙事从 `.panel` 移出 → 软底（P0-2）
2. 顶栏去数字 → 文字 + 图标；红色只在危险（P0-1）
3. 场景压暗 6% + 顶栏渐隐（P0-3）
4. 字号映射表批量替换（§3.1）
5. 阴影收敛到 3+1（§3.2）

**验收**：390×844 与 1280×900 截图各一张，与旧版并排；灰度检测文字/背景亮度差 ≥25；一屏赭石计数 ≤2。

### 阶段 B：两周
6. `ChoiceCard` 木牌（5 状态 + 三行结构）
7. `BottomSheet` 三档 + 手势阈值
8. `Seal` 印章动画（300ms）
9. `Glossary` 三层视觉层级（缩进 + 边框递减）

**验收**：组件页 1440 与 390 双档；键盘 Tab 能走完；`prefers-reduced-motion` 下无动画。

### 阶段 C：一个月
10. 字号 rem 化 + 3 个无障碍开关（宋体阅读 / 统一易读 / 减少动效）
11. 深色自动切换（夜晚）+ 大事件全局效果（降饱和 + 薄雾）
12. 图标线宽统一（文档与代码对齐）
13. CI 加 5 条检查

**验收**：200% 字号不破版；夜间截图；CI 全绿。

```powershell
# 字号直方图
$s = Select-String -Path apps\web\public\*.css -Pattern 'font-size:\s*(\d+)px' -AllMatches
$s.Matches | ForEach-Object { [int]$_.Groups[1].Value } | Group-Object | Sort-Object {[int]$_.Name}

(Get-Content apps\web\public\*.css -Raw | Select-String 'box-shadow:\s*([^;}]*)' -AllMatches).Matches.Value | Sort-Object -Unique

# 令牌使用率
$all = Get-Content apps\web\public\*.css -Raw
([regex]::Matches($all,'var\(--fs-[a-z-]+\)')).Count

# 硬编码色（排除 theme）
Select-String -Path apps\web\public\*.css -Pattern '#[0-9a-fA-F]{6}' | Where-Object Filename -ne 'theme.css' | Group-Object Filename
```

## 8. 一句话总结

**我们的色板、字体、圆角、时长都已经对了；错在三件事：把数字放回了界面、把叙事关进了卡片、让场景比界面更亮。** 这三件事都不需要重做美术，只需要改 CSS 与投影文案。
