# OpenLife 界面规范（UI 与交互第一轮，2026-10-20）

令牌定义在 `apps/web/public/theme.css`（颜色、圆角、阴影）和 `ui-polish.css`（字号、状态色、按压反馈）。新界面只用令牌，不写死颜色。

## 字号
| 令牌 | 值 | 用途 |
|---|---|---|
| `--fs-xs` | 12px | 眉标、时间戳、辅助说明 |
| `--fs-sm` | 13px | 次要正文、状态条标签 |
| `--fs-md` | 15px | 正文（body 默认） |
| `--fs-lg` | 17px | 卡片标题（衬线 `--serif`） |
| `--fs-xl` | 22px | 页面/弹窗标题（衬线） |

标题用 `--serif`（思源宋体系），正文和按钮用 `--sans`。数字一律 `font-variant-numeric: tabular-nums`。

## 颜色语义
- `--primary` 暮色青绿：主操作、选中、进度正常。
- `--accent` 日光赭石：眉标、点缀、提示条。
- 状态三档（状态条、提示）：`--ok` 不用管 / `--warn` 要留意 / `--danger` 先处理。每档都配一个文字词（“有点饿”“在漏雨”），不只靠颜色区分。
- 深色模式由同名令牌覆盖，组件不需要单独写深色规则。

## 按钮三级
1. 主按钮（实心青绿）：一屏最多一个，是“现在最该点的那个”。今日指引里的重点事项、弹窗里的确认。
2. 次按钮（描边）：其余操作。
3. 文字按钮（无边框灰字）：取消、关闭。

状态：悬停变浅青底；按下下沉 1px + 内阴影（纯文字模式也有，不依赖动画）；键盘焦点 2px 青绿描边；禁用为 55% 透明 + 去饱和 + 禁止光标；忙碌时顶部 3px 进度线 + 顶栏“正在进行…”+ `aria-busy`。

## 对话框
- 打开时焦点进入第一个输入框；Tab 在弹窗内循环；Esc 或点遮罩关闭；关闭后焦点回到打开它的按钮。
- 关闭一律触发弹窗自己的关闭按钮（`CLOSE_BUTTON` 表），新增弹窗要登记，单测会检查。
- 操作区粘在底部；≤600px 时弹窗变成贴底抽屉。

## 手机（≤600px）
- 底栏五个入口一行，选中项下方有短横条。
- 今日指引的按钮在文字下方、占满整行。
- 状态条两列，每项“标签+分级词 / 数值 / 进度条”。

## 手动验收清单
1. 首页右侧插画缺失时显示暮色河岸兜底，而不是整块深绿。
2. 新人生：Esc、点遮罩都能关；选出身后天赋卡点整张卡勾选，显示“已选 n / 2”，选满后其余变灰；“开始这段人生”不用滚动就看得见。
3. 生活页第一次进入有“三步看懂这一页”，“指给我看”依次框出今日指引、状态条、三个大按钮；关掉后刷新不再出现；菜单 → 新手引导可重新打开。
4. 状态条：屋顶漏雨显示红色“在漏雨”，鼠标悬停有说明。
5. 点任意动作，顶栏短暂出现“正在进行…”。
6. 390px 宽：底栏一行五个，无横向滚动。
