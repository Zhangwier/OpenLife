| 界面 | 以前 | 现在 |
|---|---|---|

| 人际 | 每张卡只写「陌生」两个字和固定说明 | 加上「陌生 → 见过 → 相识」三步条，高亮当前一步；附近的人显示交情 n / 10；写明下一步怎么走（「当面搭句话就算见过」「再当面聊 n 回就能相识」，和规则里聊满 3 回算相识一致）；右上角标「在附近 / 不在身边」；身边的人、更熟的人排在前面 |
